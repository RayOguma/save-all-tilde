# BGM

ゲームで流す曲を置くフォルダ。ここに置いたファイルは、ビルドすると dist/bgm/ にそのままコピーされる。

- 形式は mp3 か ogg
- 曲ごとに、出どころ（サイト名・作曲者）と利用規約（改変してよいか・クレジットの書き方）をこのファイルに書いておく

扉の錠がはずれる「カチャリ」（`"<unlock>"`）など、ほかの効果音は音声ファイルを使わず、ブラウザの中で合成している（`src/ui/sound.ts` の `sfx`）。

## クレジット

- 音楽: もみじばミュージック https://music.storyinvention.com/
  - 公開リポジトリ（GitHub）に mp3 を置くことは、もみじばミュージックさまから許可をいただいている（2026-10-07）
- 効果音: OtoLogic https://otologic.jp （CC BY 4.0）

エンディングのクレジット（`src/ui/ending.ts` の `MUSIC_CREDITS`）と、リポジトリの README にも同じものを書く。曲を足したら、この3か所をそろえる。
