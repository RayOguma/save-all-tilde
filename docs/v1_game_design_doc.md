# 卒業制作ゲーム企画書「モリビト」（仮）

## 概要

- **舞台**: プレイヤーはずっとターミナルの中にいる。ホームディレクトリ = 主人公の住む村「ネスト村」
- **ジャンル**: 謎解き・ミステリー、長編
- **コンセプト**: 村人＝ファイル、場所＝フォルダ。`cd`で移動し、`cat`で会話し、コマンドを覚えながら物語が進む
- **実装方針**: 本物のファイルシステムではなく、YAML/JSONで定義した仮想ファイルシステムを自作シェルが解釈する
- **主人公名**: プレイヤーが自由に命名（本文中は「きみ」と表記）
- **物語の核**: うっかり打ってしまった禁忌コマンドが村を壊す → 賢者のもとへ旅に出て、コマンドを学びながら村を元に戻す

### 主要用語・キャラクター（暫定ネーミング）

| 名称 | 正体 |
|---|---|
| ネスト村 | ホームディレクトリ。主人公の故郷 |
| モリビト | 村の秩序・時間を司る守護デーモンプロセス |
| オグマ爺 | ネスト村の村長 |
| リド | 旅の果てにいる賢者。実はかつてモリビトを作った本人 |
| ムラガレ | 隣村。ネスト村と同じ問題を抱えるコミュニティ |

## 第0章｜ネスト村（home） — 事件発生

**学ぶコマンド**: `ls`, `cd`, `cat`（チュートリアル）

### 仕様
- プレイヤーは`ls`で村を見渡し、`cd`で村人Aの家・村人Bの家などを行き来する練習をする
- 各村人ファイルを`cat`すると挨拶や日常会話が返る
- 村の奥、`立入禁止`フォルダに`cd`しようとすると`Permission denied`が出るが、村長の目を盗んで裏道から入れてしまう（あるいは村長に呼ばれて渡された鍵ファイルで一時的に入れる、など導入は要調整）
- 禁忌フォルダの中には`モリビト`という名の実行中プロセスファイルがあり、`cat`すると「これは何だろう」と好奇心を煽る説明文が出る
- ここでプレイヤーが`kill モリビト`（またはそれに類する操作）を実行できる状態にしておく。実行しなくても、他の行動（例えば説明文の中の指示に従う）で同じ結果に自然と誘導される保険ルートを用意する

### ストーリー
きみは生まれてからずっとネスト村で暮らしてきた。特別なことは何も知らない、ただの村人。ある日、村はずれの「立入禁止」と書かれたフォルダが気になって、こっそり足を踏み入れてしまう。

```
$ cd 立入禁止
Permission denied

$ ls -a
.モリビト

$ cat .モリビト
[実行中のプロセス]
これが何なのか、きみにはわからない。
ただ、何かとても大切なものだという気配だけはする。

$ kill モリビト
モリビトを停止しました。

...

村の様子が、少しおかしい。
```

`kill`を実行した瞬間、画面が一瞬乱れ、時間が止まったような静寂が流れる演出を入れる。

その後、`ls`で村を見渡すと村人の一部が応答しなくなっている、`cat`しても文字化けした返答しか返らない、といった異変が起こる。慌てて村長の家に戻ると、村長がかすれた声で告げる。

```
$ cat オグマ爺
オグマ爺: き…きみか…。
オグマ爺: モリビトが…止まってしまった…。
オグマ爺: わしらはもう…あまり…動けん…。
オグマ爺: 森の先、もつれ沼を越えた先に…
オグマ爺: リドという賢者がおる…。
オグマ爺: あの方なら、モリビトを…直す術を…知っておるはずじゃ…。
オグマ爺: 頼む…行ってくれ…。
```

こうして、きみは村を救うため、賢者リドを探す旅に出る。

## 第1章｜迷いの森

**学ぶコマンド**: `find`

### 仕様
- 森フォルダの中には多数のサブフォルダ（木、茂み、岩など）が入り組んで存在し、`ls`だけでは目的の「道しるべファイル」がどこにあるか分かりにくい
- `find . -name "道しるべ*"`のように名前で検索させることで正しい道を見つけられる
- 誤った道（ハズレのサブフォルダ）に入ると、軽い寄り道イベント（森の小動物ファイルとの会話など）が発生し、詰みにはならない設計にする

### ストーリー
村を出たきみは、鬱蒼とした森に迷い込む。同じような景色のフォルダが連続し、方向感覚を失っていく。

```
$ ls
茂みA/ 茂みB/ 岩場/ 倒木/ ...

$ find . -name "道しるべ*"
./倒木/裏側/道しるべ_西.txt

$ cat ./倒木/裏側/道しるべ_西.txt
道しるべ: 西へ進め。沼の匂いがする方角だ。
```

森の奥で、迷子の狐のようなファイル「コダマ」に出会う。コダマは道案内と引き換えに、`find`の使い方を教えてくれる先達として機能する。

```
$ cat コダマ
コダマ: お前、見ない顔だな。人間がここまで来るのは久しぶりだ。
コダマ: 探し物があるなら、`find`を使うといい。
コダマ: 目に見えている場所だけが、全てじゃない。
```

## 第2章｜もつれ沼

**学ぶコマンド**: `ln`（シンボリックリンク）

### 仕様
- 沼地には見た目が全く同じ「渡り道A」「渡り道B」という2つのフォルダがあるが、片方は本物の道（実体）、もう片方は既に沈んだ道への死んだリンクになっている
- `ls -la`でリンクの矢印表示を確認させ、`file`や`readlink`的な自作コマンドで実体を確認させる
- 逆に、プレイヤー自身が`ln -s`を使って、行き止まりの場所同士をショートカットで繋ぎ、正しいルートを作る謎解きを用意する
- テーマ提示: 「見た目が同じでも、中身（実体）は違うことがある」という伏線を、後の賢者リドの正体（見た目は賢者だが実体はモリビトの創造主）に繋げる

### ストーリー
沼地に着くと、2本の道が全く同じ姿で分かれている。

```
$ ls
渡り道A/ 渡り道B/

$ ls -la
lrwxrwxrwx  渡り道A -> ../沈んだ祠
drwxr-xr-x  渡り道B/
```

沼の主である老亀ファイル「コウ」が忠告をくれる。

```
$ cat コウ
コウ: 見た目が同じでも、続いている先は違う。
コウ: `-la`をつけて、よく見てみるといい。矢印がある方は…もう繋がっとらんよ。
```

正しい渡り道Bを選んで進むと、途中で行き止まりに突き当たる。ここで`ln -s`を使い、離れた岩場同士を繋いでショートカットを作ることで先へ進めるパズルを配置する。

## 第3章｜隣村ムラガレ

**学ぶコマンド**: `chmod`, パーミッションの概念

### 仕様
- ムラガレの家々の多くが`Permission denied`で入れない状態になっている。ネスト村と同じ異変が起きていることに気づかせる
- 各家に対応する「鍵」（許可情報）を村人から聞き出し、`chmod`で権限を変更して初めて入れるようにする
- 一部の家はきみに開ける権限がそもそも無く、村人自身に`chmod`してもらうよう頼む（会話コマンドで依頼する）という、プレイヤーの手だけでは完結しない謎を混ぜて多様性を出す

### ストーリー
```
$ cd 薬屋
Permission denied

$ cat 村人ハル
ハル: ああ、薬屋のじいさんもここ最近、様子がおかしくてね。
ハル: 誰も彼も、心を閉ざしちまったみたいだ。
ハル: …ここだけの話じゃないんだよ。うちの村も、何かがおかしいんだ。
```

ここで「自分の村だけの問題ではなかった」ことにきみは気づく。ムラガレの長からも、モリビトに似た存在（この村を支えていた別のプロセス）の話を聞き、伏線を仕込む。

```
$ cat ムラガレの長
ムラガレの長: この村にも、そういう"見えない支え"があったのさ。
ムラガレの長: いつの間にか、いなくなっちまった。
ムラガレの長: お前さんの村と、同じようにな。
```

## 第4章｜市場町イチバ

**学ぶコマンド**: `mv`, `cp`

### 仕様
- 謎解き色は控えめにし、コマンド習熟のための息抜き章として設計
- 商人たちから「この荷物をあっちの店に移してくれ」「これは大事なものだから、コピーを取ってから渡してくれ」といった軽い頼まれごとを複数こなす
- `mv`は移動（元の場所から消える）、`cp`は複製（元の場所にも残る）という違いを、荷物を実際に動かして体感させる

### ストーリー
きみは市場町で、旅の食料や道具を整えることになる。町の商人たちは陽気で、ここまでの緊張感から一息つける場所として機能させる。

```
$ cat 商人ゲンゾウ
ゲンゾウ: おっ、旅人さんかい。手が空いてるなら手伝っておくれよ。
ゲンゾウ: あの木箱、隣の露店に運んでほしいんだ。`mv`を使えばいい。
ゲンゾウ: あ、こっちの巻物は大事なものだから、写しを取ってから渡しとくれ。元は残しておきたいからね。
```

町の噂話として、「賢者リドはとても変わり者だが、昔はこの町にもよく顔を出していた」という情報が拾える小イベントを配置し、リドへの興味を高めておく。

## 第5章｜廃墟山道

**学ぶコマンド**: `tar`（圧縮・展開）

### 仕様
- 山道の途中、瓦礫に埋もれた「圧縮された村人」ファイル（`.tar.gz`のような形式）が複数見つかる
- `tar -xzf`で展開すると、中から本来のファイル（村人）が復元される、というカタルシス重視の章
- 全員を助けなくてもストーリーは進むが、助けた人数に応じて後半の会話やエンディングの描写が少し変化する（やり込み要素）

### ストーリー
```
$ ls
瓦礫の山/

$ cd 瓦礫の山
$ ls
旅人の記録.tar.gz

$ tar -xzf 旅人の記録.tar.gz
$ ls
旅人の記録.tar.gz  旅人カヤ/

$ cat 旅人カヤ
カヤ: う…ここは…？ 助かった…のか？
カヤ: 私は昔、ここでモリビトの噂を調べていた旅人でね。
カヤ: 崩落に巻き込まれて、そのまま…閉じ込められていたみたいだ。
カヤ: 礼を言うよ。おかげで、また息ができる。
```

助けた旅人カヤから、モリビトについての追加の伝承（次章・次々章の伏線）を聞ける。

## 第6章｜坑道アナグラ

**学ぶコマンド**: `ps`, `jobs`, `fg` / `bg`, `kill`（正しい使い方の再学習）

### 仕様
- 坑道には、姿は見えないが気配だけする「彷徨う者たち」が複数いる。これは`ps`で確認できる、バックグラウンドに追いやられた存在たち
- `ps`で一覧を確認し、`fg`で表舞台に戻してあげることで、その人物と初めて会話できるようになる
- 一人だけ、明らかに様子のおかしい暴走ぎみの存在（`ps`のCPU使用率的な表現で「異常」と分かる）がいて、これは`kill`しなければ先に進めない。ここで「同じコマンドでも、使うべき時と使ってはいけない時がある」というテーマ回収を行う

### ストーリー
```
$ ps
PID   STATE   NAME
0231  bg      迷いの鍛冶屋
0455  bg      泣く子ども
0999  RUN(暴走) 影の獣

$ fg 0231
迷いの鍛冶屋が表に現れた。

$ cat 迷いの鍛冶屋
鍛冶屋: おお…！ 誰かに気づいてもらえるのは、久しぶりだ…。
鍛冶屋: ずっと、裏側で働き続けていたんだ。誰の目にも留まらずにな。
```

暴走する「影の獣」に対しては、鍛冶屋が助言をくれる。

```
$ cat 迷いの鍛冶屋
鍛冶屋: あれはもう、正気を保っていない。放っておけば坑道ごと飲み込まれるぞ。
鍛冶屋: 辛いだろうが…`kill`するしかない。
鍛冶屋: お前が最初にモリビトにしてしまったことと、同じ言葉だ。
鍛冶屋: だが今度のそれは、必要な選択だ。忘れるな、その違いを。
```

ここで、第0章の過ちと同じコマンドを「正しい状況で」使わせることで、プレイヤー自身にコマンドの重みを再認識させる。

## 第7章｜物見の塔

**学ぶコマンド**: `cron` / `at`（時間指定処理の概念、簡易化した自作コマンドで表現）

### 仕様
- 塔の中は「時間が壊れた」場所として演出。同じ会話がループしたり、本来起こるはずだった出来事（鐘が鳴る、扉が開く）が起きなくなっている
- 壊れたスケジュール設定ファイル（`cron`のような形式）を見つけ、正しい時刻・条件に書き直すことでループを解消する
- 複数のスケジュールを組み合わせて「特定の順番で扉が開く」ようなちょっとした論理パズルにする

### ストーリー
```
$ cat 塔の記録
09:00 鐘を鳴らす
09:00 鐘を鳴らす
09:00 鐘を鳴らす
（延々と同じ行が続く）

$ cat 塔守
塔守: 見ての通りさ…。時が、同じ場所をぐるぐる回っている。
塔守: モリビトが止まってから、ずっとこの調子だ。
塔守: 正しい"予定"を、書き直してやってくれないか。
```

正しく`cron`（自作コマンド）でスケジュールを書き直すと、塔の鐘が正常に鳴り、次の扉が開く。ここで「モリビトが本来担っていた役割の大きさ」を実感させる。

## 第8章｜記憶の書庫

**学ぶコマンド**: `history`, `diff`

### 仕様
- 書庫には大量の過去ログファイルが保管されている。`history`的な形式で、モリビトが作られた経緯・過去に何度か書き換えられた形跡が記録されている
- 二つの版のログを`diff`で比較させることで、「モリビトは元々、リドという人物が作ったもの」という真相が明らかになる
- リドが過去に一度、モリビトを意図的に停止させたことがある（それも何かの事情による）という伏線もここで匂わせる

### ストーリー
```
$ ls
記録_旧.log  記録_新.log

$ diff 記録_旧.log 記録_新.log
< 作成者: リド
< モリビトは、村々を静かに見守るために作られた。
---
> 作成者: 不明
> 何者かが、モリビトの記録から作成者の名を消している。

$ cat 書庫の番人
番人: モリビトを作ったのは…リド様、その人だよ。
番人: なぜ自分の名を記録から消したのか、わしにはわからん。
番人: だが一度、リド様自身の手でモリビトを止めたことがある、という話も聞いたことがある。
```

きみは、これから会う賢者が単なる部外者ではなく、事件の核心に関わる人物だと悟る。

## 第9章｜賢者の庵 — 対峙と選択

**学ぶコマンド**: 総復習 ＋ 「逆コマンド」（モリビトを再起動させる、自作の集大成コマンド。例: `revive モリビト` や `systemctl start モリビト` 的な自作コマンド）

### 仕様
- リドとの対話パートが中心。ここまで集めた情報（第2章のシンボリックリンクの伏線＝見た目と実体の違い、第8章の記録の真相）を踏まえて、リドの正体と過去の事情が語られる
- リドは直接モリビトを直してはくれない。「直し方は教えるが、実行するのはお前自身の手でなければならない」と告げ、プレイヤーに最後の選択と実行を委ねる
- 最終コマンドは、第0章で誤って打ってしまった`kill モリビト`と対になる構造にする（例えば`revive モリビト`）。ここまでのステージで学んだ複数のコマンドを組み合わせて到達するミニパズルにしてもよい（例: `chmod`で権限を取り戻し、`tar`で保管されていたモリビトの本体データを展開し、最後に`revive`する、という複合パズル）

### ストーリー
```
$ cat リド
リド: よく来た。長い旅だったろう。
リド: …そして、もう気づいているんだろう？ モリビトを作ったのは、私だ。

$ cat リド
リド: 私はかつて、自分の手でモリビトを止めたことがある。
リド: 力を持ちすぎた見守り役は、村を縛る鎖にもなり得ると気づいたからだ。
リド: だが、完全に手放す勇気もなくてね。中途半端に、また動かしてしまった。
リド: そして今度は、お前がそれを止めた。皮肉なものだ。

$ cat リド
リド: 直し方は教えよう。だが、これはお前がやるべきことだ。
リド: お前の村を、お前の手で。
```

最終的にプレイヤーが`revive モリビト`（あるいは複合コマンド）を実行すると、村の時間が動き出す演出が入る。

**エンディング分岐案（第5章の救出人数などに応じて変化させる）**:
- **完全復元エンド**: モリビトは元通りに動き出し、村人たちも記憶を取り戻す
- **ほろ苦い復元エンド**: モリビトは動き出すが、一部の記憶・データは失われたまま。村人の一部が「何かが違う気がする」と呟く
- **継承エンド**: モリビトそのものは完全には戻らないが、代わりにきみ自身が新しい"見守り役"としての役目の一端を担うことになる（リドの立場ときみの立場が重なる締めくくり）

## 全体を通した設計メモ

- **コマンドの再利用**: `grep`は森の看板・書庫のログなど複数章で応用させ、`ls -la`は第2章以降習慣的に使わせることで定着を図る
- **フラグ管理**: 各章の進行状況・救出人数・選択などをフラグとして持ち、村人の`cat`結果やエンディングの分岐に反映させる
- **禁忌コマンドと最終コマンドの対構造**: `kill モリビト`（過ち）↔ `revive モリビト`（贖罪）という対称性を軸に、シナリオ全体の一貫性を保つ
- **見た目と実体というテーマ**: 第2章（シンボリックリンク）で提示し、第8〜9章（リドの正体）で回収する
- **緩急設計**: 第4章（市場町）を意図的に軽めにし、長編でも間延びしないようにする
