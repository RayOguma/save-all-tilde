**全体を通す線**
- `kill モリビト`（過ち）↔ `sudo systemctl start モリビト`（贖い）
- 見た目と実体（第2章で提示 → 第8・9章で回収）
- 「見えない支え」＝裏で動くプロセス（第0章の窯、第3章ムラガレ、第6章の坑道、第7章の塔）
- `sudo`: 第0章では「きみには、まだその資格がない」→ 第9章でスドウから資格を与えられる

**エンディングに影響するフラグ**
- 第3章: ムラガレで開けた家の数
- 第5章: 助けた旅人の数
- 第6章: 表に戻した（`fg`）人の数
- 第9章: 結末は「スドウから鍵束を託され、新しい見守り役になる」の1つにした（エンディングの最後に、つづき（見守り役編）をにおわせる）

## 世界の構成 ✅ 案B（本物のLinuxのフォルダ構成）に決定

**案A（今の企画書）**: 全部ファンタジーの地名。`~/賢者への道/迷いの森/…` と奥へ進んでいく。
- 良い点: 旅の雰囲気が出る
- 悪い点: 章が進むとパスがとても長くなる。本物のLinuxの知識にはつながらない

**案B（採用）**: 世界の地図を **本物のLinuxのフォルダ構成** に合わせる。マップにはファンタジーの地名を表示し、横に本当のパスを小さく添える。

| 場所 | 本物のパス | 対応している理由 |
|---|---|---|
| 世界 | `/` | ルート＝世界全体 |
| チルダ村 | `/home/チルダ村`（= `~`） | ホームディレクトリ＝故郷 |
| 隣村ムラガレ | `/home/ムラガレ` | 他人のホームには権限がなくて入れない → `chmod` の章にぴったり |
| 迷いの森 | `/usr` | Linuxで一番広くて深いフォルダ → `find` がないと迷う |
| もつれ沼 | `/lib` | 実際にシンボリックリンクだらけの場所 |
| 市場町イチバ | `/tmp` | みんなが荷物を一時的に置いていく場所 |
| 廃墟山道 | `/var/backups` | バックアップ（圧縮ファイル）が眠る場所 |
| 坑道アナグラ | `/proc` | 本物のLinuxでもプロセスの情報がある場所 |
| 物見の塔 | `/etc` | 設定ファイル（cronの予定表もここ）の場所 |
| 記憶の書庫 | `/var/log` | ログ＝記録の場所 |
| 賢者の庵 | `/root` | 管理者（root）のホーム。**スドウ＝root（管理者）** |

- 良い点: クリアした人が本物のLinuxを触ったとき「`/var/log` は書庫だ」と分かる。スドウが「管理者」なので `sudo` の物語と自然につながる。パスが短く、英字なので打ちやすい
- 悪い点: 旅の順番とフォルダの並びが一致しない → マップの `？？？` と、物語で道が開く演出で旅の感覚を補う

## 第0章｜チルダ村 — 日常と過ち（約15分、チュートリアル）

**学ぶコマンド**: `ls` `cd` `cat` `pwd` `ls -a` ／ 禁忌の `kill`

**マップ**
```
チルダ村 (~)
├── きみの家/       ├ 自分の部屋/（ベッド・窓・本棚）  └ リビング/（お母さん・食卓）
├── 掲示板
├── チョウン爺の家/   チョウン爺・古い日記
├── パン屋/         パン屋のナノ・焼きたてパン
├── 井戸端/         ヴィム婆・イーマ爺・子どものピコ・井戸
├── キャット        （広場をうろつく猫）
├── 村はずれ/       看板
│   ├── 立入禁止/   🔒（村長しか入れない）
│   └── 柵の裏/     古い柵
│       └── .抜け穴/   古い石碑・.モリビト ⚙（所有者: スドウ）
└── ？？？ → 賢者への道/（異変のあと判明）
```

**流れ**: 自分の部屋で目覚める → お母さんにパンのおつかいを頼まれる → パン屋（ナノ）→ 家に届ける → チョウン爺におすそわけ（立入禁止の警告）→ ピコから抜け穴の秘密 → 石碑とモリビト → 禁忌 → 異変（お母さんも止まる）→ 村長の頼み → 旅立ち。細かい流れは [chapters/ch0.md](chapters/ch0.md)、セリフは [chapters/ch0_script.md](chapters/ch0_script.md)。

- `kill` をためらって打たない人向けの保険: 石碑を2回読むと「文字が淡く光り、きみの口が勝手に動きそうになる……」と誘導が強まる
- 📝 チョウン爺のせりふに、プレイヤーの名前を呼ばせる場面を増やすか

## 第1章｜迷いの森 — 探す力

**学ぶコマンド**: `find`（`-name`、`*`、`-type d`）

鈴を失くした森の精コダマに出会い、`find` を教わって、鈴と3枚の道しるべを探し、出口の苔むした門を見つける。コダマが仲間として旅に加わる（地図に表示、どこでも話せる、ヒントの声になる）。

細かい流れは [chapters/ch1.md](chapters/ch1.md)。

**伏線**: 野営のあとのスドウの置き手紙（― S）、コダマ「前に通ったのは、杖をついた白髪の男」

## 第2章｜もつれ沼 — 見た目と実体

**学ぶコマンド**: `ls -l`（リンクの矢印）、`file`、`ln -s`、`unlink`

同じ姿の二本道の片方はリンク切れ。沼の主の老亀ツナギに `ls -l` を、カエル兄弟の騒ぎで `file`（正体を調べる）を覚え、`ln -s` で道のない所に飛び石をつないで沼を渡る。沼の底の沈んだ祠に「モリビト試作一号 ― S」。向こう岸の「ムラガレへの近道」（リンク）をたどって第3章へ。

細かい流れは [chapters/ch2.md](chapters/ch2.md)。

## 第3章｜ムラガレ — 心を閉ざした村

**学ぶコマンド**: `ls -l` の鍵（rwx・持ち主・組）、`chmod`（記号のみ）、`groups`、`write`

チルダ村と同じく「見えない支え」を失い、家々の扉が閉ざされた村。長のグロウプ婆に鍵の読み方を教わり、譲られた空き家を `chmod` で開ける。鍛冶屋の兄の妹ハルに、兄と同じ持病が出はじめたため、閉じこもった薬屋のじいさんに `write` で薬を頼む。組の者だけが入れる物置から薬草を取って届けると、ハルの薬と、坑道へ行ったきりの兄の分の薬を託される（第6章の伏線）。

細かい流れは [chapters/ch3.md](chapters/ch3.md)。

## 第4章｜市場町イチバ — 息抜き（約10分）

**学ぶコマンド**: `mkdir`、`mv`（移動・名前の変更）、`cp`、`cp -r`

にぎやかな市場町。商人アプトの木箱を `mv` で隣の果物屋へ運び、旅のかばん `~/かばん` を `mkdir` で作る（ふるさとにつながった、きみだけのかばん。第5章の `tar`、第9章で使う）。書写屋のディディ爺から地図の巻物を `cp` で、スドウの覚え書きを `cp -r` で写してかばんへ。看板屋のリネの書きまちがい「八百尾」を `mv` で「八百屋」に直し、楽師ピップに `mkdir 舞台` で舞台を作る。宿屋の女将から「スドウはいつも重たそうな鍵束を下げていた（root の伏線）。市場の片づけ番を気にして、山道へ向かった」と聞く。小さな異変として、売れ残りが片づかなくなっている（町の「見えない支え」も弱りはじめている）。

細かい流れは [chapters/ch4.md](chapters/ch4.md)。

## 第5章｜廃墟山道 — 眠る人々（約12分）

**学ぶコマンド**: `tar -tzf`（ほどかずに中を確かめる）、`tar -xzf`（ほどく）、`tar -czf`（まとめる）

くわしくは [chapters/ch5.md](chapters/ch5.md)。

**マップ**
```
/var/backups（廃墟山道）
├── 関所/            関所番イプタ。通行証（第4章）を見せると通れる
├── 崩れた宿場/      スドウの書き置き、耳石、カヤ・石工・羊飼い・崩れた荷（中にまた包み）の .tar.gz
├── 古い祠/          古い箱.tar.gz（中身はモリビトの設計図。第9章で使う）
└── 狭い抜け道/      坑道アナグラ（第6章）へ
```

**流れ**
1. 関所で `cat ~/かばん/通行証` を見せて通る（第4章の通行証の回収）
2. 崩れた宿場に、包まれて眠る人々。スドウの書き置き「ほどくときは、まず中をあらためよ」→ `tar -tzf` で中を確かめてから `tar -xzf` でほどく → 宿場の聞き番カヤが目を覚ます
3. カヤの家は代々、耳石に響く遠い守り人の鼓動を聞いて、山の支えの調子を見てきた。「前から少しずつ弱っていた鼓動が、ある日ぷつりと止まり、山が崩れた」→ 主人公は、それが自分が `kill` した日だと知る
4. 崩れる前に、スドウがみんなを包みにして守った（人を守る力も、少しこわい力もある人）。スドウを探していると話すと、もういないこと、包みながら「わしも年じゃ。あとを継ぐ者を探さねば」とつぶやいていたこと（継承エンドの伏線）、崖の向こうの祠に箱を置いていったことを思い出す
5. 寄り道で、石工メイク・羊飼いヤム・崩れた荷の中のジップ（包みの中に包み。2回ほどく）も助けられる
6. 崖の向こうの祠へは、「祠」とつく場所を `find` で探して、`ln -s` で渡る。箱の中は、なにかの設計図らしい紙の束（第4章の覚え書き三枚目「設計図は山道に預けた」の回収。モリビトの物とは、まだ分からない）。`mv` で「設計図」と名札をつけ、添え書きのとおり `tar -czf` でまとめて、かばんへ
7. カヤに知らせに戻ると、この先の道を教えてくれる。スドウも抜け道のほうへ歩いていった（どこまで行ったかは分からない）→ 狭い抜け道から坑道アナグラへ

**フラグ**: 助けた人数（カヤのほかに 0〜3）、設計図を見つけたか

## 第6章｜坑道アナグラ — 正しい kill（約15〜20分）

**学ぶコマンド**: `ps`、`fg`、`bg`、`kill`（番号＝PIDで指定）、`chgrp`

くわしくは [chapters/ch6.md](chapters/ch6.md)。

**マップ**
```
/proc（坑道アナグラ）
├── 点呼板            ps を覚える
├── 0231番通路/       ノーハップ（ハルの兄）が裏で働いている
├── 0455番通路/       ミナシゴが眠っている
├── 0999番通路/       影の獣のすみか
└── 深い坑道/分かれ道/…/古い竪坑/   獣が現れる分かれ道と、出口（find で探す）
```

**流れ**
1. 真っ暗な坑道。点呼板で `ps` を覚え、見えない者たちの番号を知る（通路の名前と同じ番号）
2. 裏で働くノーハップに `write` で声をかけ、`fg 0231` で表に呼ぶ。第3章の薬を渡し、ムラガレの組に入れてもらった話をする。薬の礼に、出口まで案内してくれる
3. ミナシゴを `fg` で呼ぶ。「親がいなくなったら、守り人さまが拾ってくれるはずだった」← 主人公の `kill` がここにも届いていた（言い出せない）。「賢者に会えば、親のこともなんとかなるかもしれない」と励まし、`bg` で裏に隠れていてもらう
4. ノーハップの案内で坑道を進む（「次は `cd 深い坑道` だ」）。分かれ道で、影の獣が突然現れる。「ムラガレの組の者しか入れない場所を作れば、一緒に隠れられる！」→ **3分の時間制限**（残り時間は見せない）で、ノーハップに教わりながら `mkdir 隠れ場` → `chgrp ムラガレ 隠れ場` → `chmod`。間に合わなければゲームオーバー（直前からやり直し）
5. 獣は去るが「このままじゃ進めない」→「`kill` するしかないか」→「`kill`！？」→「今度のそれは、必要な選択だ。番号を、よく確かめろ」→ `kill 0999` → 獣が「……ムラ……ガレ……」（ムラガレの見えない支えの成れの果て）
6. まちがえてノーハップやミナシゴを `kill` したら、ゲームオーバー（コダマが離れ、主人公は自責の念で動けなくなる）。唱える前からやり直す
7. 「この先の古い竪坑が出口だ」→ `find` で探して抜ける。スドウも竪坑のほうへ抜けていった（どこまで行ったかは分からない）

**フラグ**: 表に呼んだ人数

**クリア後**: ミナシゴに会いに行ける（エンディングのあとの物語で考える 📝）

## 第7章｜物見の塔 — 止まった時間（約15分）

**学ぶコマンド**: `date`、`echo`、`>` と `>>`、`crontab`（`crontab 紙` で渡す・`crontab -l` で見る）

くわしくは [chapters/ch7.md](chapters/ch7.md)。

**マップ**
```
/etc（物見の塔）
├── クロン・塔の記録・大時計・予定表・銅の扉の札
└── 銅の扉/（銀の扉の札）→ 銀の扉/（金の扉の札）→ 金の扉/ → 頂上/
```

**流れ**
1. 古い竪坑のはしごを登ると、鐘が鳴りやまない塔の中。`cat 塔の記録` → 「09:00 鐘を鳴らす」が延々と続く
2. 塔守クロン（cron）に `date` を教わる。何度唱えても 7月12日 09:00:00 ―― 時が止まっている
3. `cat 予定表` → `* * * * * 鐘を鳴らす`（毎分鳴らすので、鳴るたびに塔は9時に戻ってしまう）。予定表の書き方（分 時 日 月 曜日）を教わる
4. 書き直す前に、写しをとる（`cp 予定表 予定表.bak`）。予定表を預かり、鍵を確かめて自分に書く鍵を開ける（`ls -l` → `chmod u+w`）
5. コダマが、自分の名のもとになった `echo` を教える。`echo "0 9 * * * 鐘を鳴らす" > 予定表` → `crontab 予定表` で塔に渡すと、時が動きだす
6. 3つの扉を予定表で順番に開ける: 銅の扉は朝の鐘と同じ刻、銀の扉は銅の扉の30分後、金の扉は「今日という日の正午」（`date` で今日の日付を確かめ、日と月の欄まで書く）。書き足しは `>>`。`>` で書くと鐘の行が消え、大時計がまた止まる
7. 塔の頂上で景色を見渡す → **地図の残りの `？？？`（記憶の書庫・賢者の庵）が名前に変わる**
8. クロン:「チルダ村の窯が毎朝6時に火がつくのも、予定表の仕事。世界じゅうの予定を毎朝回させていたのは、モリビトさまじゃ」→ 第0章の窯の話とつながる。鍵束の男は、谷の書庫のほうを見ていた

本物の `crontab -e` はエディタを開くので、`echo >` で紙に書いてから `crontab 紙` で渡す形にした（本物でも使える書き方）

## 第8章｜記憶の書庫 — 真相（約12分）

**学ぶコマンド**: `grep`、`diff`、`history`、`|`（パイプ）

くわしくは [chapters/ch8.md](chapters/ch8.md)。

**流れ**
1. 番人シスロ（syslog）に `grep` を教わる。`grep モリビト *.log` で村々の記録を探すと、どの村も「7月12日 09:00 モリビト、停止」（塔の大時計が止まった時刻）。書庫の記録に「スドウ、モリビトの記録を書き換える」
2. 守り人の記録は「作成者: 不明」。`ls -a` で隠された古い版 `.守り人.log.1` を見つけ、`diff` で見比べる → 「作成者: スドウ」「作成者みずから、一度だけ守り人を止めたことがある。十日のあいだ、世界の時は止まった」が消されていた
3. 原本（作成者が自分の手で書いた、いちばん最初の記録）は、作成者の手元に置く決まり。スドウは名前も歩みの記録も消したが、『守り人の原本』の札だけは残っていた → 札は `/root/庵/守り人の原本`（賢者の庵）を指している（`file`）
3'. 十年前の記録を `grep` すると「モリビトを直すには、守り人の設計図と、作成者の鍵束がいる」。`ls ~/かばん` で、第5章で預かった設計図があることを確かめる → あとはスドウの鍵束。会えば直せる（旅の目的に戻る）
4. 書庫の奥に **きみ自身の記録** がある → `history`。「スドウは記録を消した。でも自分は消さずに、止めたのは自分だと話して、直してほしいと頼む。だから、あの日の言葉を確かめたい」→ `history | grep kill` で、`kill .モリビト`（過ち）と `kill 0999`（坑道で、みんなを守るために唱えた）が並ぶ（メタ演出）
5. 過ちの行から墨があふれ、「記録の影」が主人公を包みこもうとする。第1章のコダマの首飾りが光って守る。「過ちの記録は消えぬ。じゃが、記録に呑まれる必要もない」「記録は消せない。でも、書き足すことはできる」
6. スドウは自分の名を記録から消したが、主人公は自分の記録から目をそらさなかった。コダマ「われらが旅に出たのは、モリビトを動かしなおし、チルダ村を元に戻すため」。設計図はある。スドウの鍵束で、モリビトを直してもらうために、賢者の庵へ

## 第9章｜賢者の庵 — 対峙と選択（約20分）

**学ぶコマンド**: `sudo`、`systemctl start`、総復習

くわしくは [chapters/ch9.md](chapters/ch9.md)（作ったもの）。下は、もとの案。

**流れ**
1. 庵は `Permission denied`（所有者: root）。入口にスドウの試練が3つ（総復習）
   - 散らばった鍵を `find` で探す／錆びた錠を `chmod` で開ける／封印された巻物を `tar` で解く
2. スドウとの対話: 正体（モリビトの作者、root）、かつてモリビトを止めた理由（「見守り役は、村を縛る鎖にもなり得る」）
3. スドウ:「直し方は教えよう。だが、お前の手でやれ」→ **`sudo` の資格を与えられる**（第0章の「まだ資格がない」の回収）
4. チルダ村へ戻る（`cd ~`）→ `.抜け穴` → 止まったモリビト
5. 第5章の設計図（`tar -xzf`）で本体を直し、`sudo systemctl start モリビト` で再起動する
6. 村の時間が動き出す → エンディング

**エンディング**

| エンド | 条件（案） | 内容 |
|---|---|---|
| 完全復元 | 救出系フラグの合計が多い（第3・5・6章） | モリビトは元通りに動き、村人も記憶を取り戻す |
| ほろ苦い復元 | 上記以外 | モリビトは動くが、一部の記憶は戻らない。「何かが違う気がする」 |
| 継承 | 最後の選択で「自分が見守る」を選ぶ | きみが新しい見守り役（管理者）になる。スドウの立場と重なる |

- 最後の選択はフォルダで表す: `選択_モリビトに託す/` と `選択_きみが見守る/` のどちらに `cd` するか
- エンドロールのあとに「本物のLinuxで試してみよう」ページ
