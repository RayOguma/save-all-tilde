## 💡 ヒント（3段階）

**「第2章クリア」**

1. 第2章はここまで。遊んでくれてありがとう！

**「向こう岸に着いた」**

1. 向こう岸の道しるべ「ムラガレへの近道」は、リンクだ。
2. リンクには、ふつうの場所と同じように `cd` で入れる。
3. `cd ムラガレへの近道`

**「found_far_shore」**

1. 向こう岸の住所は `/lib/向こう岸`。中州でしたのと同じように、葦の原から飛び石をつなごう。
2. `ln -s 行き先 名前` で、行き先を指さす飛び石ができる。
3. `ln -s /lib/向こう岸 飛び石` → `cd 飛び石`

**「葦の原に渡った」**

1. 向こう岸の場所は、まだ分からない。まずは探そう。
2. 場所を探すなら `find -type d`。「岸」の字を含む場所を探そう。見つけたら、葦の原に飛び石をつなぐ。
3. `find /lib -type d -name "*岸*"` → `ln -s /lib/向こう岸 飛び石` → `cd 飛び石`

**「中州に渡った」**

1. 中州の立て札に、次の行き先が書いてある。
2. 中州で `ln -s 行き先 名前` と唱えれば、飛び石をつなげる。
3. `cat 立て札` → `ln -s /lib/葦の原 飛び石` → `cd 飛び石`

**「ln -s を教わった」**

1. ツナギの言うとおり、岩場から中州へ飛び石をつなごう。
2. `ln -s` のあとに「行き先」、そのあとに「つくる飛び石の名前」を書く。
3. `ln -s /lib/中州 飛び石` → `cd 飛び石`（間違えたら `unlink 飛び石` で切れる）

**「カエル弟の正体が分かった」**

1. カエルたちは静かになった。岩場のツナギに知らせよう。
2. ツナギは渡り道Bの先、岩場にいる。
3. `cd /lib/渡り道B/岩場` → `cat ツナギ`

**「file を教わった」**

1. カエル兄とカエル弟は、本当に別々のカエルなのだろうか。
2. 正体を調べるには `file`。
3. `file /lib/浮き草/カエル弟`

**「ツナギに会った」**

1. 浮き草のカエルたちが、うるさいらしい。兄にも弟にも、話しかけてみよう。
2. 浮き草は、沼の入口（/lib）にある。
3. `cd /lib/浮き草` → `cat カエル兄` → `cat カエル弟`

**いつも**

1. そっくりな二本道がある。どちらにも、進んでみよう。
2. 渡り道Aは、入れないようだ。渡り道Bの奥へ行ってみよう。
3. `cd 渡り道B` → `cd 岩場` → `cat ツナギ`
