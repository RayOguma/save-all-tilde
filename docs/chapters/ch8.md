## 1. 概要

| 項目 | 内容 |
|---|---|
| 場所 | 記憶の書庫（`/var/log`）。本物のLinuxでも、記録（ログ）が集まる場所。古い記録に `.1` をつけてとっておくのも本物と同じ |
| 長さ | 12〜15分くらい |
| 覚えること | `grep 言葉 紙`（言葉を含む行だけを抜き出す）、`*.log`（まとめて探す）、`diff 紙1 紙2`（ちがう行だけを見比べる）、`history`（自分の記録）、`\|`（パイプ。`history \| grep kill`） |
| おさらい | `*`（`*.log`。第1章の `find`）、`ls -a`（隠された古い版。第0章）、`groups`（書庫番の組。第3章）、`ls ~/かばん`（設計図。第4章）、`file`・`ls -l`（『原本』の札はリンク切れ。第2章） |
| 新しい人物 | シスロ（書庫の番人。syslog）、記録の影 |
| 枠 | 色とりどりの背表紙が並ぶ本棚 |
| BGM | 湖上の社（書庫）、レクイエム（奥の間） |
| 旅の目的 | モリビトを直して、チルダ村を元に戻す。十年前、スドウは止めたモリビトを「設計図と作成者の鍵束」で動かしなおした。設計図はかばんにある → あとはスドウの鍵束 |
| テーマ | 真相: モリビトを作ったのはスドウ。スドウも一度、自分の手でモリビトを止めていた。スドウは記録から自分の名を消したが、主人公は自分の記録（`kill .モリビト`）から目をそらさない |
| 山場 | `history \| grep kill` で自分の過ちの行を見た瞬間、墨があふれて「記録の影」になり、主人公を包みこもうとする。第1章のコダマの首飾りが光って守る（伏線の回収） |

## 2. 用語のたとえ

| 用語 | この世界での例え | 誰が |
|---|---|---|
| ログ | 世界じゅうの出来事が、毎日書きこまれる記録 | シスロ |
| `grep` | 言葉で探す。その言葉を含む行だけを抜き出す | シスロ |
| `*.log` | 「.log で終わる紙ぜんぶ」（迷いの森の `*` と同じしるし） | シスロ |
| `.1`（ログのローテーション） | 古くなった記録は、名のうしろに `.1` をつけて棚にとっておく（書庫の掟） | 書庫の掟・シスロ |
| `diff` | 二枚の記録を見比べる。`<` は前の紙だけ、`>` はあとの紙だけにある行 | シスロ |
| `history` | 自分が唱えてきた言葉の記録 | シスロ |
| `\|`（パイプ） | 左の言葉が出した行を、そのまま grep に流しこむ | シスロ |

├── 守り人の棚/        書庫番の組だけ入れる。守り人.log（作成者: 不明）・.守り人.log.1（隠された古い版。作成者: スドウ）・守り人の原本 -> /root/庵/守り人の原本（原本＝作成者が自分の手で書いた、いちばん最初の記録。作成者の手元に置く決まりで、札はそのありかを指す）

## 4. 流れ

| # | 場面 | 操作 | 覚えること |
|---|---|---|---|
| 1 | 塔を降りて、谷の底の書庫へ | `ls` | |
| 2 | 番人シスロは、スドウの行き先を聞かれて「旅人の歩みはふつう記録に残るのに、スドウ様の歩みだけは、ところどころ抜け落ちている」。そして「記録はとても多い。言葉で探すんです」。`grep` のうしろに、探したい言葉と、探す記録の名前。`*` を知っているのは「あなたが森で使ったことも、この書庫に記録されていますから」（奥の間の伏線） | `cat シスロ` | `grep`・`*.log` |

## 6. 作るもの（システム）

- `grep 言葉 紙...`: 紙（`text`）から、言葉を含む行を出す。紙が2枚以上なら `紙:行`。`-n`（行の番号）・`-i`。紙の名前の `*` は、いまの場所の名前に広がる
- `diff 紙1 紙2`: 本物と同じ書き方（`2c2`・`5d4`・`3a4`、`<`・`---`・`>`）
- パイプ `|`: 左のコマンドの出す行を集めて、右の `grep` に流しこむ（`|` のうしろは grep だけ）。イベントの `from`
- `history`: 1000行まで残す。`kill` の行は、古くなっても消さない。章の `clear` の `history` で、「章を選ぶ」で始めたときも記録が残る
- イベントの `identified`（リンクの正体を見破ったとき）
- 演出 `"<shadow>"`（曲が消え、画面が暗く沈み、ザザッと乱れる）・`"<light>"`（首飾りの光と、鈴の音）
- 章の終わり（`chapterEnd`）では、ステージの曲を消す。次の章の始まりまで流さない（`src/ui/music.ts` の `holdMusic`）
- シナリオのリンクを `unlink` で抜いたことも、セーブの `ops` に残す（しくみだけ。第8章では使わない）
