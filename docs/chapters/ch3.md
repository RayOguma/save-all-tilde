## 1. 概要

| 項目 | 内容 |
|---|---|
| 場所 | ムラガレ（`/home/ムラガレ`）。チルダ村の隣の村。本物のLinuxでは「他人のホーム」＝勝手に入れない場所 |
| 長さ | 第2章と同じくらい（20〜25分） |
| 覚えること | `ls -l` の鍵（`rwxr-x---`）の読み方、持ち主と組（グループ）、`chmod`（記号の書き方のみ）、`groups`、`write` |
| おさらい | `find`（薬草を探す）、`ls 場所`（のぞく）、`file` |
| 新しい人物 | グロウプ婆（ムラガレの長）、村人ハル、薬屋のじいさん |
| 枠 | どす黒い空（チルダ村と同じ。この村も「見えない支え」を失っている） |
| テーマ | 自分の村だけの問題じゃなかった。他人の持ち物は、本人にしか開けられない。閉じた扉ごしでも、声は届く |
| チルダ村との違い | 守り人の失われ方で、傷み方が違う。チルダ村は `kill` で一瞬で止められたので、時ごと凍りつき、村人は話せない。ムラガレの支えは少しずつ弱って消えたので、時は流れているが、ぬくもりが抜けていく（人は話せるが心が冷えて扉を閉ざし、作物は育たず、病も重くなりやすい）。第6章で、ムラガレの支えは止まったのではなく、正気を失って坑道をさまよっていた（ゾンビプロセス）と分かる |

## 2. 用語のたとえ

| 用語 | この世界での例え | 誰が |
|---|---|---|
| パーミッション（`rwxr-x---`） | 家の扉にかかった鍵のかけ方 | グロウプ婆 |
| r / w / x | r＝窓から中をのぞける／w＝中に物を置ける／x＝扉を開けて入れる | グロウプ婆 |
| 3組の rwx | 左から「持ち主」「家族（同じ組の人）」「よその人」への許し | グロウプ婆 |
| 持ち主（owner） | その家の主。鍵のかけ方を変えられるのは主だけ | グロウプ婆 |
| 組（group） | 同じ組の人は家族のようなもの。家族にだけ開いている扉がある | グロウプ婆 |
| `chmod` | 自分の家の鍵のかけ方を変える言葉。u＝自分・g＝家族・o＝よその人、＋で開ける、－で閉める | グロウプ婆 |
| Operation not permitted | 「おまえの家ではない」と扉に言われる | ナレーション |
| `write` | 閉じた扉のすきまに手紙を差しこむように、声を届ける | グロウプ婆 |

## 3. 地図（案）

```
/home/ムラガレ                   drwxr-xr-x  グロウプ婆  （入れる）
├── 掲示板
├── ハル                         広場にいる、ただ一人の村人
├── グロウプ婆の家/              drwxr-xr-x  グロウプ婆  （入れる）
├── 空き家/                      d---------  グロウプ婆 → きみ に譲られる
├── 薬屋/                        drwx------  薬屋のじいさん
├── 鍛冶場/                      drwxr--r--  ノーハップ    （のぞけるけど入れない。ハルの兄。第6章）
│   └── 兄の手紙                 「坑道へ行ってくる」（第6章の伏線）
├── 物置/                        drwxrwx---  グロウプ婆・組:ムラガレ （組の人だけ入れる）
│   └── 薬草 など
└── 裏の畑/ ...                  寄り道
```

`ls -l` に「組」の列を足す（本物どおり: `drwxrwx---  グロウプ婆  ムラガレ  物置/`）。

## 4. 流れ

| # | 場面 | 操作 | 覚えること |
|---|---|---|---|
| 1 | 近道を抜けると、色のない村。どの家も `cd` すると Permission denied | `ls` → `cd 薬屋` | |
| 2 | 広場のハルが咳をしている。「あんたの村も？」「村長のグロウプ婆に会うといいよ」（兄の話はまだしない。グロウプ婆が空き家で話す） | `cat ハル` | |
| 3 | グロウプ婆の家。`ls -l` の鍵の読み方を教わる（r・w・x、3組。`drwx------` の先頭の `d` は主人公が「ひとつ多いよ」と聞き、「先頭の一文字は、何かのしるし。`d` は場所、`-` は人や物、`l` はリンク」と教わる）。「この村にも"見えない支え"がいた」。空き家を譲られ、持ち主が「きみ」になる（チョウン爺＝`chown` の回収）。`chmod` の唱え方は、主人公の合いの手をはさみながら「だれの（`u` `g` `o`）」「開けるか閉めるか（`+` `-`）」「どの鍵（`r` `w` `x`）」の順に教わり、最後に `chmod u+rwx ../空き家` と、そのまま打てる形で聞く | `cat グロウプ婆` | 鍵の読み方、持ち主、組、`chmod` |
| 4 | 空き家の鍵は全部閉じている → 自分の家なので、自分で鍵を変えられる。`x` がつくと「カチリ」と錠がはずれ、主人公「開いた……！」コダマ「入ってみるがよい」（`x` がつかないうちは、コダマが「中へ入る鍵は `x`」） | `chmod u+rwx 空き家` → `cd 空き家` | `chmod` |
| 5 | 空き家に入ると、閉じた扉の外からグロウプ婆が `write {name}` と声を届けてくる。組「ムラガレ」に入れてもらえる。グロウプ婆「ハルの兄は鍛冶屋でな、同じ胸の病を持っとった。薬屋のじいさんに薬を頼んでくれんか。扉は閉まっとっても、声は届く」 | `groups` | `groups`、`write` |
| 6 | 薬屋に `chmod` しようとすると「Operation not permitted」 | `chmod o+x 薬屋` | 持ち主だけが変えられる |
| 7 | `write` でハルの薬を頼む。じいさん「咳の音が、ここまで聞こえとった。ハルじゃろう。薬草を切らして、薬が作れん。物置の薬草を持ってきてくれ」 | `write 薬屋のじいさん "ハルの薬をください"` | `write` |
| 8 | 薬草は、組の人だけが入れる物置にある。中は棚や箱でごちゃごちゃで、コダマ「探しものなら、森で覚えた言葉があったろう」→ 棚の下の段に見つかる（`find` のおさらい） | `ls -l` → `cd 物置` → `find . -name "*薬草*"` → `cat 棚/下の段/干した薬草` | 家族（組）の許し |
| 9 | 薬草を知らせると、じいさんが薬を作り、扉を開けてくれる（`drwx---r-x` に変わる） | `write 薬屋のじいさん "薬草を持ってきました"` | 持ち主が鍵を変える |
| 10 | 薬屋でハルの薬と、兄の分の薬を受け取る。じいさん「わしは足が悪うて、坑道までは行けん。行くことがあったら渡してくれ」→ コダマ「坑道アナグラ……名だけは知っておる。スドウを追うなら、いずれ通ることになろう」（道は知らない。第4章「この先の道は、われも知らぬ。地図がいるな」へつながる）→ 主人公「必ず届けます」（第6章の伏線） | `cd 薬屋` → `cat 薬屋のじいさん` | |
| 11 | ハルに薬を届けると、咳がおさまる。「兄さんがいつも飲んでた薬と、同じ匂いがする」「兄さんを、頼んだよ」「グロウプ婆が、あんたが戻ったら顔を出すように言ってたよ」（グロウプ婆のところへの導線） | `cat ハル` | |
| 12 | （寄り道）鍛冶場は `r--` だけ。`ls 鍛冶場` で中の手紙の名前は見えるが、入れない | `ls 鍛冶場` | r だけ・x がない |
| 13 | グロウプ婆に知らせる →「なんでこの村へ来なすった？」→「スドウを探している」→「どこへ向かう？」→「坑道アナグラ」→「なら、イチバを通っていくとええ。坑道へは、イチバの先の山道を越えていく」→ コダマと話して章の終わり | `cat グロウプ婆` | |

### write の反応（書いた言葉で変わる）

言葉の意味を理解するのではなく、決まった言葉が入っているかで見分ける。

| 書いた言葉の例 | 薬屋のじいさんの反応 |
|---|---|
| 「お願い」「ください」「薬」「ハル」など、頼みごと | 「……ふむ、礼儀を知っとるな。薬がいるのか。咳の音が、ここまで聞こえとった」→ 薬草を頼まれる |
| 「開けろ」「早く」など、乱暴な言い方 | 「……なんじゃその口のきき方は」と怒られる（何度でもやり直せる） |
| 「薬草」を含む（薬草を持っているとき） | 薬を作って、扉を開けてくれる |
| それ以外 | 「……用件はなんじゃ？」（何を書けばいいかのヒント） |

## 5. 作るもの（システム）

- 組（グループ）: ノードに `group`、プレイヤーの入っている組（セーブに残す）。`can()` を 持ち主／組／その他 の3組で判定する
- `ls -l` に組の列
- `chmod`（記号のみ: `u` `g` `o` `a`、`+` `-` `=`、`r` `w` `x`）。持ち主が「きみ」の物だけ。それ以外は Operation not permitted
- `groups`
- `write 名前 "ことば"`: 名前の人に声を届ける。シナリオで、言葉に含まれる語ごとに反応を書けるようにする
- 物語の都合で持ち主や鍵を変える（空き家を譲られる、じいさんが扉を開ける）: イベントに `chown` / `chmod` のような設定
- ムラガレの立ち絵（グロウプ婆・ハル・薬屋のじいさん）、村のアイコン

## 6. 決まったこと

- 3組（持ち主・家族・よその人）をちゃんと教える。家族（組）の場面として、組の人だけ入れる物置を置く
- `chmod` は記号の書き方だけ。数字（`755`）は手帳の「本物のLinuxでは」で触れる程度
- ムラガレの長の名前はグロウプ婆（GROUP のローマ字読み）
- `write` は、書いた言葉によって反応を変える

- write の反応は上の表の4つ（ていねい／乱暴／薬草の話／それ以外）
- 章の終わりは、グロウプ婆にイチバのことを聞いたあと、コダマと話して終わる。第4章ができたら、第4章の始まりの場所（`/tmp`）へ移る
