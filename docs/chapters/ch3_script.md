## 💡 ヒント（3段階）

**「ハルに薬を届けた」**

1. ハルに薬を届けたことを、グロウプ婆に知らせよう。
2. グロウプ婆の家は、ムラガレ（`/home/ムラガレ`）の中にある。
3. `cd /home/ムラガレ/グロウプ婆の家` → `cat グロウプ婆`

**「薬を受け取った」**

1. ハルに、胸の薬を届けよう。
2. ハルは、ムラガレ（`/home/ムラガレ`）の中にいる。
3. `cd /home/ムラガレ` → `cat ハル`

**「薬屋が扉を開けた」**

1. 薬屋のじいさんが、扉を開けてくれた。薬を取りに行こう。
2. `ls -l` で見ると、薬屋の鍵の右の三文字（よその人）に x がついたはずだ。
3. `cd /home/ムラガレ/薬屋` → `cat 薬屋のじいさん`

**「薬草を手に入れた」**

1. 薬草が手に入った。じいさんに知らせよう。
2. 閉じた扉ごしに声を届けるのは `write`。ことばに「薬草」を入れよう。
3. `write 薬屋のじいさん "薬草を持ってきました"`

**「薬草を頼まれた」**

1. 薬草は、村の物置にあるらしい。物置は、村の組の者しか入れない。
2. `ls -l` で物置の鍵を見よう。真ん中の三文字は「家族（同じ組の人）」への許しだ。`groups` で、自分の組も確かめよう。
3. `cd /home/ムラガレ/物置` → `find . -name "*薬草*"` → `cat 棚/下の段/干した薬草`

**「ハルの薬を頼まれた」**

1. 薬屋の扉は閉まっている。でも、声なら届く。ハルの薬を頼もう。
2. `write 名前 "ことば"` で声を届けよう。ていねいに頼むのが大事だ。
3. `write 薬屋のじいさん "ハルの薬をください"`

**「空き家の鍵を開けた」**

1. 空き家の鍵が開いた。中に入ってみよう。
2. 空き家は、ムラガレ（`/home/ムラガレ`）の中にある。
3. `cd /home/ムラガレ/空き家`

**「グロウプ婆に会った」**

1. 空き家は、もうきみのものだ。自分の家なら、鍵のかけ方を変えられる。
2. `chmod` のあとに「だれに」「開けるか閉めるか」「どの鍵」を書く。`u` は自分、`+` は開ける、`rwx` はぜんぶの鍵。
3. `chmod u+rwx /home/ムラガレ/空き家` → `cd /home/ムラガレ/空き家`

**「ハルと話した」**

1. 村長のグロウプ婆の家だけは、まだ開いているらしい。
2. グロウプ婆の家は、ムラガレ（`/home/ムラガレ`）の中にある。
3. `cd グロウプ婆の家` → `cat グロウプ婆`

**いつも**

1. 村の中に、誰かいるようだ。
2. 話しかけるには `cat`。
3. `ls` → `cat ハル`
