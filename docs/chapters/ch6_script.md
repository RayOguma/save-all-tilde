## 💡 ヒント（3段階）

**「第6章クリア」**

1. 第6章はここまで。遊んでくれてありがとう！

**「影の獣を止めた」**

1. ノーハップによると、出口は「古い竪坑」。場所は、探せば分かる。
2. 探しものは `find`。「竪坑」とつく場所を探そう。
3. `find /proc -name "*竪坑*"` → 見つけた道のりへ `cd`

**「隠れ場に隠れた」**

1. 影の獣を、止めるしかない。番号を、よく確かめよう。
2. 番号は `ps` で分かる。止めるのは `kill 番号`。
3. `ps` → `kill 0999`

**「影の獣が現れた」**

1. 急げ！ ムラガレの組の者だけが入れる隠れ場を作ろう。
2. 場所を作る → 組を変える → 家族に開けて、よその者に閉める。
3. `mkdir 隠れ場` → `chgrp ムラガレ 隠れ場` → `chmod g+rwx,o-rwx 隠れ場`

**「ミナシゴを裏に隠した」**

1. ノーハップの案内で、坑道の奥へ進もう。
2. まずは深い坑道へ。その先が、分かれ道だ。
3. `cd /proc/深い坑道` → `cd 分かれ道`

**「ミナシゴと話した」**

1. この先の道は危ない。ミナシゴを、裏に隠してあげよう。
2. 裏に戻すのは `bg 番号`。
3. `bg 0455`

**「ノーハップに薬を渡した」**

1. ノーハップが、ミナシゴのことを頼んできた。
2. ミナシゴの番号は、`ps` で分かる。表に呼ぶのは `fg 番号`。
3. `fg 0455` → `cat ミナシゴ`

**「ノーハップを表に呼んだ」**

1. 表に出てきたノーハップと、話そう。
2. 話しかけるのは `cat`。
3. `cat ノーハップ`

**「ノーハップに声をかけた」**

1. ノーハップを、表に呼ぼう。
2. 表に呼ぶのは `fg 番号`。番号は `ps` で分かる。
3. `fg 0231`

**「はじめて ps した」**

1. ハルの兄は、裏で働いていて姿が見えない。でも、声なら届くかもしれない。
2. 扉の向こうの人に声を届けたのは `write`（第3章）。ハルの兄の名前は、`ps` で分かる。
3. `write ノーハップ "ハルから、薬を預かってきました"`

**「点呼板を読んだ」**

1. 目には見えない者たちを、点呼しよう。
2. 点呼するのは `ps`。
3. `ps`

**いつも**

1. 暗い坑道。なにか、手がかりになるものはないだろうか。
2. まわりを見るのは `ls`、読むのは `cat`。
3. `ls` → `cat 点呼板`
