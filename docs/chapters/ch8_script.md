## 💡 ヒント（3段階）

**「ch8_clear」**

1. 第8章はここまで。遊んでくれてありがとう！

**「read_history」**

1. あの日、モリビトを止めたときに唱えた言葉を、自分の記録から探そう。
2. `|` で、`history` の出した行を `grep` に流しこむ。探す言葉は、あの日唱えた言葉。
3. `history | grep kill`

**「read_ledger」**

1. 自分の記録を読もう。
2. これまで唱えた言葉は `history` で読める。
3. `history`

**「found_origin」**

1. シスロが、奥の間で待っている。
2. 奥の間に、きみの記録がある。`cd` で行って、`cat` で読もう。
3. `cd /var/log/奥の間` → `cat きみの記録`

**「checked_bag」**

1. 原本は、作成者の手元にある。『守り人の原本』の札が、どこを指しているのか調べよう。
2. 札の正体を調べるのは、もつれ沼で覚えた言葉。鍵のかけ方と一緒に見る言葉でも分かる。
3. `cd /var/log/守り人の棚` → `file 守り人の原本`（または `ls -l`）

**「restart_known」**

1. 設計図は、山道の祠で預かったはず。かばんの中を確かめよう。
2. 入らずに中をのぞく言葉で、かばんの住所を書く。
3. `ls ~/かばん`

**「diff_seen」**

1. 十日止まったときの記録が、昔の記録の棚にあるはず。
2. `grep` で、たくさんの記録からまとめて探そう。
3. `cd /var/log/昔の記録` → `grep モリビト *.log`

**「told_diff」**

1. 古い版と今の版の記録を、見比べよう。
2. 見比べるのは `diff 古い記録 新しい記録`。
3. `diff .守り人.log.1 守り人.log`

**「read_record」**

1. 古い版の記録（名前のうしろに `.1`）が、棚のどこかに隠されているはず。
2. 隠れているものを見るのは、チルダ村で覚えた言葉。
3. `ls -a`

**「grep_found」**

1. 守り人の棚で、モリビトの記録を読もう。棚は、書庫番の組の者だけが入れる。
2. 棚へ行って、記録を読む。入っている組は、ムラガレで覚えた言葉で確かめられる。
3. `cd /var/log/守り人の棚` → `ls` → `cat 守り人.log`

**「met_syslo」**

1. 村々の記録から、モリビトのことを探そう。
2. 言葉で探すのは `grep`。`*` で、たくさんの記録をまとめて探せる。
3. `cd 村々の記録` → `grep モリビト *.log`

**いつも**

1. 書庫の中に、だれかいるようだ。
2. まわりを見るのは `ls`、話しかけるのは `cat`。
3. `ls` → `cat シスロ`
