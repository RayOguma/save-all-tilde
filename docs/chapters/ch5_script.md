## 💡 ヒント（3段階）

**「第5章クリア」**

1. 第5章はここまで。遊んでくれてありがとう！

**「カヤに知らせた」**

1. カヤによると、狭い抜け道の先は、坑道アナグラに出る。
2. 狭い抜け道は、山道の入口（`/var/backups`）にある。
3. `cd /var/backups/狭い抜け道`

**「設計図をかばんにしまった」**

1. 祠の箱のことを、カヤに知らせよう。
2. カヤは、崩れた宿場の、瓦礫の山にいる。
3. `cd /var/backups/崩れた宿場/瓦礫の山` → `cat カヤ`

**「設計図をまとめた」**

1. 設計図の包みなら、かばんに入りそうだ。
2. 運ぶのは `mv`。かばんの住所は `~/かばん`。
3. `mv 設計図.tar.gz ~/かばん/`

**「添え書きを読んだ」**

1. 設計図の束は大きすぎて、かばんに入らない。添え書きに、まとめ方が書いてあった。
2. まとめるのは `tar -czf 新しい包みの名前 まとめる物`。
3. `tar -czf 設計図.tar.gz 設計図`

**「紙の束に「設計図」と名札をつけた」**

1. 箱の中には、添え書きもあった。読んでみよう。
2. 読むのは `cat`。
3. `cat 添え書き`

**「設計図を見つけた」**

1. 名もない紙の束では、どれがどれだか分からなくなる。「設計図」と名前をつけておこう。
2. 名前を変えるのは `mv`（第4章で、看板の名前を直した）。
3. `mv 紙の束 設計図`

**「古い祠に渡った」**

1. 古い箱は、包みだ。ほどく前に、中をあらためよう。
2. `tar -tzf` でのぞいてから、包みのそばで `tar -xzf` でほどく。
3. `tar -tzf 古い箱.tar.gz` → `tar -xzf 古い箱.tar.gz`

**「カヤから祠の話を聞いた」**

1. 古い祠は、崖の向こうにある。道は途切れている。
2. 沼でしたように、飛び石（リンク）をつなげば渡れる。行き先の祠の住所は、「祠」とつく場所を探せば分かる。
3. `cd /var/backups/崖の上` → `find /var/backups -name "*祠*"` → `ln -s /var/backups/古い祠 飛び石` → `cd 飛び石`

**「カヤから鼓動の話を聞いた」**

1. スドウを探していることを、カヤに話してみよう。
2. カヤは、崩れた宿場の、瓦礫の山にいる。
3. `cd /var/backups/崩れた宿場/瓦礫の山` → `cat カヤ`

**「カヤを助けた」**

1. 包みから出てきたカヤに、話を聞こう。
2. 話しかけるのは `cat`。
3. `cat カヤ`

**「スドウの書き置きを読んだ」**

1. 包みの名前を見ると、中に人がいそうだ。ほどく前に、中をあらためよう。
2. `tar -tzf 包み` でのぞき、包みのそばで `tar -xzf 包み` でほどく。
3. `cd /var/backups/崩れた宿場/瓦礫の山` → `tar -tzf カヤ.tar.gz` → `tar -xzf カヤ.tar.gz`

**「関所で通行証を見せた」**

1. 崩れた宿場の瓦礫のどこかで、だれかが眠っている。そばの石に、書き置きがある。
2. 読むのは `cat`。
3. `cd /var/backups/崩れた宿場` → `cat スドウの書き置き`

**いつも**

2. 通行証は、かばんの中だ。読んで見せよう。
3. `cat ~/かばん/通行証`
