## 1. 概要

| 項目 | 内容 |
|---|---|
| 場所 | 賢者の庵（`/root`）。本物のLinuxでも、管理者（root）の家。スドウ＝sudo＝root の力 |
| 長さ | 20分くらい（エンディングを入れて） |
| 覚えること | `sudo`（鍵束の力で唱える）、`systemctl start`（守り人を動かす。sudo がいる）、`systemctl status`（動いているか確かめる） |
| おさらい（総復習） | `find`（一の試練: 三本の鍵。隠れた `.霧の奥` も）、`chmod`（二の試練: 錆びた箱）、`tar -xzf`（封じられた巻物・設計図）、`ls -l`・`file`・`unlink`（三の試練: 惑わしの札を抜く）、`cp`（`sudo cp` で設計図を抜け穴へ）、`ls -a`・`cd ~` |
| 新しい人物 | スドウ（賢者。モリビトの作成者） |
| 枠 | 雲の上（金色の空と雲）、庵の中（障子） |
| BGM | 悠久の空へ（庵）。モリビトが目をさますと、抜け穴の中は「復活の祈り２」、村へ出るとチルダ村の曲（水平線を見据えて）が戻る。エンディングは「エンディング・テーマ」 |
| 旅の目的の回収 | モリビトを動かしなおし、チルダ村を元に戻す |
| 伏線の回収 | 第0章「（きみには、まだその資格がない。）」→ スドウに sudo の資格をもらう。第4章の覚え書き「どんな扉でも開けられる鍵束を、ひとりの人間が持つべきではない」→ スドウが姿を隠したわけ。第5章の設計図 → 守り人を動かす。第8章の札 →「わざと残した」 |

## 2. 用語のたとえ

| 用語 | この世界での例え | 誰が |
|---|---|---|
| `sudo`（root） | 鍵束の力。どんな鍵も開く。唱えるときは、言葉の前に `sudo` | スドウ |
| sudo の心得 | 一つ、ほかの人の領分を尊ぶ。二つ、唱える前によく考える。三つ、大きな力には大きな責任がともなう（本物の sudo が、はじめに出す言葉） | スドウ |
| `systemctl` | 守り人（サービス）を動かす・確かめる言葉 | スドウ・守り人の原本 |
| PID 1（systemd） | 守り人。世界でいちばん最初に目をさまし、いちばん最後まで眠らない、すべての者の親 | 守り人の原本 |

## 3. 地図

```
/root（賢者の庵・雲の上の庭）
├── 試練の碑          三つの試練
├── 鍵の形の雲         （find で一緒に出てくる、まぎらわしい物）
├── 雲の小道/苔むした灯籠/一本目の鍵
├── .霧の奥/二本目の鍵        ls -a でしか見えない（find なら見つかる）
├── 風見の台/鳥の巣/三本目の鍵
├── 錆びた箱/          きみの物だが、鍵がぜんぶ閉まっている（---------）。封じられた巻物.tar.gz
├── 道しるべの辻/       東の道しるべ -> /root/庵（抜けない）・西 -> /root/消えた橋・北 -> /root/崩れた階段（リンク切れ）
└── 庵/               スドウの物（rwx------）。三つの試練を越えると開く。スドウ・守り人の原本

/home/チルダ村/村はずれ/柵の裏/.抜け穴（スドウの場所。書きこむには sudo）
└── .モリビト          sudo systemctl start モリビト で目をさます
/home/チルダ村/きみの家/玄関（第0章から置いてある）   スドウ・.コダマ（お母さんと再会したあと）
```

## 4. 流れ

| # | 場面 | 操作 | 覚えること |
|---|---|---|---|
| 1 | 書庫の屋根から空へ。雲の上の庭 | `ls` → `cat 試練の碑` | |
| 2 | 一の試練: 三本の鍵（隠れた場所にも） | `find /root -name "*鍵*"` | `find` のおさらい |
| 3 | 二の試練: 錆びた箱（きみの物）を開け、巻物をほどく。巻物「惑わしの札は、どこも指さぬ」 | `chmod u+rwx 錆びた箱` → `tar -xzf 封じられた巻物.tar.gz` → `cat 巻物` | `chmod`・`tar` のおさらい |
| 4 | 三の試練: 道しるべの辻。どこも指さない札（リンク切れ）を抜く。庵を指す札は抜けない | `ls -l` → `unlink 西の道しるべ` → `unlink 北の道しるべ` | `ls -l`・`unlink` のおさらい |
| 5 | 庵の扉が開く。スドウ「来たか。書庫の札を、たどってきたのじゃな」。スドウは、コダマを「迷いの森の精霊どの」と呼んで頭を下げる（第1章で、森の門を教えてもらった）。主人公は、はじめてコダマのすごさを知る（「ずっと、しゃべる狐だと思ってた……」「しゃべる狐で、悪かったの」） | `cd 東の道しるべ`（または `cd /root/庵`） | |
| 6 | 主人公が打ち明ける。スドウも十年前に止めたこと。鍵束の力が怖くなり、動かしなおしたとき原本に「作成者の手では、二度と守り人を動かせぬ」と書き加えて、自分の手を縛ったこと（だから今回は直せなかった）。だれかに託すしかないが、まちがった者には渡せない → 過ちから目をそらさず自分の足で来る者に託そうと、道しるべ（設計図・覚え書き・書庫の札）を残したこと。鍵を一本渡され、`sudo`（スドウの名のもと）と三つの心得を教わる。主人公はお礼を言う | `cat スドウ` | `sudo`・`systemctl` |
| 7 | チルダ村へ帰る。かばんの設計図の包みを、モリビトのそばに置く。抜け穴はスドウの場所 → `sudo` で運ぶ（写してもよい） | `cd ~/村はずれ/柵の裏/.抜け穴` → `sudo mv ~/かばん/設計図.tar.gz .` | `sudo`、`mv` のおさらい |
| 8 | 守り人のそばで設計図をほどき、鍵束の力で動かす。鼓動が戻り、「復活の祈り」が一度だけ流れて、画面が真っ白に。白から戻ると、村に色が戻っている（曲が終わると、チルダ村の曲へ）。主人公はスドウにお礼を言う | `tar -xzf 設計図.tar.gz` → `sudo systemctl start モリビト`（`systemctl status モリビト`） | `systemctl` |
| 9 | 家族のもとへ。お母さん「おかえり」。そのあと、耳もとでコダマの声（「……{name}。」）がして、玄関へ | `cd ~/きみの家/リビング` → `cat お母さん` → `cd ../玄関` | |
| 10 | 玄関で `ls` するとスドウ（お礼を言い、鍵束を託されて、新しい見守り役に）。`ls -a` すると隠れたコダマ（第1章と同じ。森へ帰るお別れ）。ふたりと話すとエンディング（章ごとの挿絵と覚えたコマンド → 制作 → Thank you for playing）→ 真っ暗な中に、スドウ「石碑の警告を削り取ったのは、わしではない」「見守り役の仕事は、ここからが本番じゃぞ」（スペースで進める） | `ls` → `cat スドウ` → `ls -a` → `cat .コダマ` | |

- 村の人たち（バッシュ・ナノ・チョウン爺・ピコ・ヴィム婆とイーマ爺・キャット）にも、目をさましたあとのせりふがある（寄り道）
- 目をさましたモリビトに `kill` を唱えようとすると、唱えずにやめる（「唱える前に、よく考える」）

## 5. エンディング（`src/ui/ending.ts`）

- 最後の章（`chapter.ending`）をクリアすると、章の終わりの画面のかわりに流れる
- エンディング・テーマを流しながら、第0章から第9章までの「章の終わりの幕」の絵を、ひとつ6.5秒ずつ入れかえる（下に「第N章 題」。最後の絵には、結末の名前 `endingTitles` も）。奇数章は絵が左、偶数章は絵が右
- 絵の隣に、その章で覚えたコマンドと、短い使い方を、動かさずに出す（章の `clear.learned` と、手帳の `usage`・`summary`・オプションの `short` から作る。第0章は、はじめから使える ls・cd・cat も）
- 絵が終わったら、画面を真っ暗にして、曲を4秒かけて消す。音がなくなってから、真ん中に「制作　RayOguma」→ 消えて「Thank you for playing!」→「タイトルへ」
- 「Thank you for playing!」が消えたあと、真っ暗な中に、スドウの立ち絵とせりふを1行ずつ出す（章の `epilogue`。スペース・Enter・クリックで進める）。本編で明かしていない「石碑の警告を削り取ったのは、だれか」を残して、見守り役（管理者）としての物語がつづくことをにおわせる
- 右下の「スキップ ▶▶」で、真っ暗になるところまで飛ばせる
