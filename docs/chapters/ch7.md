## 2. 用語のたとえ

| 用語 | この世界での例え | 誰が |
|---|---|---|
| `date` | 大時計に、今の日時を聞く | クロン |
| `echo` | こだま。言ったことが、そのまま返ってくる（コダマの名のもと） | コダマ |
| `>` | 声を紙に写す。紙は書き直され、前の字は消える | コダマ |
| `>>` | 紙のいちばん下に、書き足す | クロン |
| cron・`crontab` | 塔守が、渡された予定表のとおりに、毎日の仕事を回す。`crontab 紙` で塔に渡す、`crontab -l` で塔が覚えている予定を見る | クロン |
| 予定表の書き方 | 左から「分 時 日 月 曜日」、そのうしろに仕事。`*` は「いつでも」 | クロン |
| `.bak` | 書き直す前にとっておく写し。名前のうしろに `.bak`（backup の略）をつけるのが昔からの決まり | クロン |

## 3. 地図

```
/etc（物見の塔）
├── クロン            塔守。うたた寝しては「9時じゃ」と言う
├── 塔の記録          「09:00 鐘を鳴らす」が延々と続く
├── 大時計            date で日時を確かめる（止まっている間は、何度見ても 09:00:00）
├── 予定表            * * * * * 鐘を鳴らす（毎分鳴らしてしまう）。鍵は r--r--r--（先代が封じた）
├── 銅の扉の札
└── 銅の扉/              予定表で開く（一の扉。朝の鐘と同じ刻）
    ├── 銀の扉の札
    └── 銀の扉/          銅の扉の30分後
        ├── 金の扉の札
        └── 金の扉/      今日という日の、正午にだけ（日と月を date で確かめる）
            └── 頂上/  見晴らし。地図の残りの「？？？」が、名前に変わる
```

- 予定表は、ふつうの物と同じく `cat` で読める。中身は、せりふではなく紙に書かれた字（`text`）
- `echo "…" > 紙` で書けるのは、物語で頼まれた紙（章の `allow` に `cmd: echo`）だけ

## 4. 流れ

| # | 場面 | 操作 | 覚えること |
|---|---|---|---|
| 1 | 古い竪坑のはしごを登ると、塔の中。カーン、カーン……と、鐘が鳴りやまない（直すまで、本当に1分おきに鐘の音が鳴る） | `ls` | |
| 2 | 塔の記録を読むと「09:00 鐘を鳴らす」ばかり | `cat 塔の記録` | |
| 3 | 塔守クロンは、うたた寝から覚めては「9時じゃ」。「大時計に聞けば分かる。`date` と唱えてみなされ」 | `cat クロン` | `date` |
| 4 | `date` は何度唱えても 7月12日（火）09:00:00。主人公「{me}が村を出た日だ。あれから何日も旅してきたのに」「時が、止まっている……」（塔の暦は、モリビトが止まった7月12日の朝のまま。外では7月19日） | `date` | |
| 5 | クロン「塔は、予定表のとおりに鐘を鳴らし、時を進める」→ 予定表は `* * * * * 鐘を鳴らす`。左から分・時・日・月・曜日、`*` は「いつでも」。毎分鳴るたびに、塔は「9時の鐘」と思いこんで時計を戻してしまう。本当は `0 9 * * *`（毎日9時0分に一度だけ） | `cat 予定表` | 予定表の書き方 |
| 6 | クロン「書き直してくれんか。……その前に、先代の予定表の写しを、`予定表.bak` という名でとっておいてくれ」 | `cp 予定表 予定表.bak` | `cp` のおさらい |
| 7 | クロンが予定表を預けてくれる（持ち主がきみに）。「先代が、うっかり書きかえられぬよう、鍵をかけておったはず」→ 鍵を確かめて、自分に書く鍵を開ける | `ls -l` → `chmod u+w 予定表` | `ls -l`・`chmod` のおさらい |
| 8 | コダマ「紙に書くには、われの名のもとになった言葉がある」→ `echo やっほー` → そのまま返ってくる →「うしろに `>` と紙の名を書けば、声が紙に写る」 | `echo やっほー` → `echo "0 9 * * * 鐘を鳴らす" > 予定表` | `echo`・`>` |
| 9 | クロン「書けたら、`crontab 予定表` で塔に渡してくだされ」→ 大時計の針が動きだす。鐘が、一度だけ鳴る | `crontab 予定表` | `crontab` |
| 10 | 銅の扉の札「朝の鐘と同じ刻に、開く」。クロン「書き足すときは `>>`。`>` では、前の字が消えてしまう」 | `echo "0 9 * * * 銅の扉を開ける" >> 予定表` → `crontab 予定表` | `>>` |
| 11 | 銀の扉の札「銅の扉が開いてから、30分ののちに」 | `… "30 9 * * * 銀の扉を開ける" >> 予定表` → `crontab 予定表` | |
| 12 | 金の扉の札「今日という日の、正午にだけ開く」→ `date` で今日（7月12日）を確かめて、日と月まで書く | `date` → `… "0 12 12 7 * 金の扉を開ける" >> 予定表` → `crontab 予定表` | 日・月の欄 |
| 13 | 頂上。見晴らしから、まだ行っていない場所が見える（地図の「？？？」が名前に変わる）。クロン「チルダ村の窯が、毎朝6時にひとりでに火がつかなんだか。あれも予定表の仕事じゃ。……世界じゅうの予定を、毎朝起こして回していたのが、モリビトさまじゃ」 | `cd 頂上` | |
| 14 | 鍵束の男（スドウ）は、頂上から書庫のほうを見ていた。章の終わり（次は記憶の書庫） | | |

- `>` で扉の行を書くと、鐘の行が消える → `crontab` で渡すと、鐘が鳴らずに大時計がまた止まる。クロン「鐘の予定が消えておる！ `>` は書き直し、`>>` は書き足しじゃ」→ 鐘の行を書き直してから、もう一度
- `*` を `"` で囲まずに `echo` すると、本物では `*` がまわりの物の名前に化ける。ゲームでは書かずに「`"` で囲もう」と教える
- 予定表の行の形がおかしい（欄が足りない、数でない）と、`crontab` は受け取らない（本物と同じ）。クロンが直し方を教える（予定表を読んで確かめ、`>` で書き直してから、残りの行を `>>` で書き足す）
- 鐘が直ると、大時計がカチ、コチと動きだす（秒針の音）
- 頂上で、主人公が「{me}が止めた」とはじめて打ち明ける。クロンは驚き、責めずに「止めてしまったものは、また動かせる」と言う。コダマは「やはり、そうであったか」（うすうす気づいていた）
- 扉は、銅の扉 → 銀の扉 → 金の扉（登るほど、よい金属に）

## 5. 作るもの（システム）

- `date`: 章の `date: [{ if, text }]` から、今の日時を出す（止まっている間は同じ時刻）
- `echo ことば`: そのまま出す。`> 紙` で書き直し、`>> 紙` で書き足し。書ける紙は、章の `allow` に `cmd: echo` で書いたものだけ（書く鍵 `w` も要る）。書いた中身はセーブの `texts` に残る
- 物の `text`: 紙に書かれた字。`cat` すると、せりふではなく字のまま出る
- `crontab 紙`: 紙の各行を「分 時 日 月 曜日 仕事」として読み、章の `cron.jobs` と照らし合わせて、フラグを立てる（合っていれば `flag`、仕事の名が書いてあれば `flag_written`）。そのあと `cron.onInstall` の、条件が合った最初のイベント。`crontab -l` で、渡した予定を見る（セーブの `crontab`）
- 物にも `onChmod`（予定表に書く鍵がついたとき）
- 頂上で、`/var/log`（記憶の書庫）と `/root`（賢者の庵）を地図に出す（`reveal` と、光る演出）

📝 本物の `crontab -e` はエディタを開くので、`echo` で紙に書いてから `crontab 紙` で渡す形にした（本物でも使える書き方）
