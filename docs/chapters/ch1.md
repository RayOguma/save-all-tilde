## 1. 概要

| 項目 | 内容 |
|---|---|
| 場所 | 迷いの森（`/usr`）。本物のLinuxで一番広くて深いフォルダ |
| 長さ | 第0章と同じか、それ以上（20〜25分） |
| 覚えること | `find`（名前で探す → `*` で「〜で始まるもの」→ `-type d` で場所だけ）、探し始める場所（`.` と `/usr`）、`cd` せずに遠くの物を `cat` する、`cd -`（さっきいた場所へ戻る）、`ls 場所`（入らずにのぞく） |
| おさらい | `ls -a`（隠れた森の精）、`pwd` と `cd ..`（迷ったとき）、`/` から書く道のり |
| 新しい仲間 | コダマ（落ち着いた古い森の精。狐の姿）。この章の終わりから旅に加わる。地図に「仲間」として表示し、どこでも `cat コダマ` で話せる。ヒントの声にもなる |
| テーマ | 村の外は色鮮やか。灰色になった村との対比で「止まったのは村だけ」と分かる。そして「目に見える場所だけが、すべてではない」 |

- 順番を飛ばしても詰まない（例: 先に苔の道で遊んでもよい）
- 赤い「!」は第0章と同じく、次に行く場所・話す相手に付ける。ただし探し物（鈴・首飾り・道しるべ・門）には、`find` で見つけるまで付けない。見つけたあとの首飾りと道しるべには付ける（シナリオの `seen`）

## 4. コダマ

- **姿**: 白い狐。尾に鈴をつけていた
- **性格**: 落ち着いた古い森の精。長く森に棲み、人の子をやさしく見守る。多くは語らず、問いかけるように教える
- **一人称・口調**: 「われ」。「〜だな」「〜よ」「〜であろう」「〜するがよい」
- **名前の由来**: 木霊＝こだま＝`echo`（第7章で `echo` を覚えるときに回収できる）
- **せりふの例**
  - 出会い: 「……だれ……だれ……？」（こだまのように返ってくる）→「……ふむ。人の子か。久しく、見なかったな」
  - 「われはコダマ。この森に棲む、古い木霊よ」
  - 「探し物があるなら、find と唱えるがよい」
  - 「目に見えるものだけが、すべてではない。……おまえは、もう知っているようだな」
  - 「その言葉は、唱えた場所から下しか見ない。森のすべてを探すなら、森の入口から唱えるがよい」
  - 「……前にここを通った人の子は、杖をついた白髪の男だった。おまえと同じ目をしていたな」（＝スドウ）
- **仲間になってから**
  - 地図の下に「仲間」の欄を作り、コダマの立ち絵と名前を出す
  - どこにいても `cat コダマ` で話せる。今いる場所や物語の進み具合に合わせて、ひとこと感想やヒントをくれる（例: 沼で「ふむ……同じ顔をした道が二つ。どちらかは、偽りであろう」）
  - ヒント（💡）はコダマの声で、立ち絵つきで出す

## 6. 作るもの（システム）

- `find` コマンド: `find 場所 -name 名前`、`*` の使える名前、`-type d`／`-type f`。結果は本物と同じ形（`/usr/倒木/うろ/枯れ葉の山/鈴`）。見つかった場所は地図に載る
- 章をまたいだ世界: 今は第0章のシナリオ1つで世界を作っている。章ごとのYAMLを重ねて1つの世界にする仕組み
- 章の切り替え: 章の見出し、ヘッダーの章の表示、村の「色が抜ける」の解除
- 効果音: 鈴の「チリーン」。シナリオの演出（`effect: bell` など）から鳴らせるようにする。設定の音のオン・オフに従う
- 仲間: 地図の下の「仲間」欄。仲間はどこにいても `cat 名前` で話せる（場所や進み具合でせりふが変わる）
- ヒントの話し手: 仲間がいるときは、ヒントを仲間の声（立ち絵つき）で出す
- 新しい立ち絵とアイコン: コダマ、リス、フクロウ、倒木・切り株・小川・霧・門など

## 7. 決まったこと

- 言葉が木から生まれる設定（言葉の木立）は入れない。`find` はコダマから教わる
- 鈴を返したときは「チリーン」という効果音を鳴らす
- コダマは旅についてくる。地図に「仲間」として表示し、どこでも話せる

- 設定の音は「文字の音」と「効果音」を別々にオン・オフできる
