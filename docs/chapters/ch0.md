## 1. 画面のどこに何を出すか

```
┌ ヘッダー ────────────────────────────────────────────────────┐
│ モリビト ～ save -a ~ ～   第0章 チルダ村     [📖手帳][💡ヒント][❓遊び方] │
├ 地図 ──────────────┬ ターミナル ─────────────────────────────────┤
│ ？？？              │ ユウ@moribito:~/パン屋$ cat ナノ              │
│  └ ？？？           │ ┌──────────────────────────────┐           │
│     └ 🏠 チルダ村 ~  │ │[立ち絵] ナノ                   │ ← 会話    │
│        ├ 📋 掲示板   │ │        いらっしゃい、ユウ！      │           │
│        ├ 🍞 パン屋 ◀ │ │        ねえ聞いて。……          │           │
│        │  ├ 👤 ナノ  │ └──────────────────────────────┘           │
│        │  └ 📜 パン  │ （焼きたての香りが……）         ← ナレーション │
│        └ …          │ [/ がついている名前は「場所」。] ← システム  │
├ 目的 ──────────────┤ ┌ 入力候補 ───────┐                          │
│ 🎯 井戸端でピコを探そう │ │ cd  場所を移動する│                          │
│                    │ └───────────────┘                          │
│                    │ ユウ@moribito:~/パン屋$ c▌        ← 入力欄   │
└────────────────────┴────────────────────────────────────────────┘
```

| 出すもの | 場所 | 見た目 |
|---|---|---|
| 会話 | ターミナルの流れの中 | 枠の中に **立ち絵（ドット絵）→右に名前→その下にせりふ**。1文字ずつ表示。キーかクリックで全文表示。1つ出し終えたら右下に ▼ を出して、スペース（Enter・クリック）で次のせりふへ。しばらく進まなければ ▼ の左に「スペースで次へ」。最後のせりふのあと、そのまま入力待ちになるときは待たない |
| 兄の手本 | 入力欄 | 入力欄を太いオレンジの枠で囲み、「⌨ バッシュが入力中……」の札。Tab・Enter を押すときは、入力欄の上に大きなキーと説明（「Tab キーを押すと、名前の残りを補ってくれる」）を1.6秒ほど見せてから押す |
| ナレーション | ターミナル | 灰色の文字「（…）」 |
| システムの案内 | ターミナル | 赤い文字「[…]」。操作の説明に使う |
| コマンドの結果 | ターミナル | 場所＝青、人＝黄、プロセス＝赤 |
| 今やること | 左下「🎯 目的」 | 変わるたびに一瞬光る |
| 次に行く場所 | 地図 | アイコンの左に赤い「!」（ゆっくり上下に揺れる） |
| 新しく覚えたコマンド | 右上の通知 ＋ 右の手帳のカードが光る | 「📖 手帳に ○○ が追加された」。kill は唱えるまで紫（謎の言葉）、唱えたあとは赤（禁じられた言葉） |
| 覚えたコマンドの書き方 | 右の「📖 コマンド手帳」（いつも出しておく） | 名前・ひとこと・書き方・覚えたオプション（`cd ..` `cd ~` など）。クリックで入力欄へ。「くわしく」で引き出し。「📖 手帳」ボタンで閉じる／開く。幅 1100px 以下の画面では出さず、引き出しで見る |
| コマンドの説明（くわしく） | 右の手帳の「くわしく」→ 右から出るパネル | できること／書き方／オプション／例／本物のLinuxでは。「入力する」で入力欄へ |
| ヒント | 「💡 ヒント」ボタン、または `hint` | 押すたびに 方向性 → 使うコマンド → 答え の3段階 |
| 遊び方 | 「❓ 遊び方」ボタン | 画面の部品（地図・ターミナル・手帳・ヒント）の案内をまとめて見られる。はじめに自動では出さず、第0章で兄がそれにまつわるコマンドを使うときに、吹き出しで1つずつ紹介する（ターミナル → `ls` の結果・地図・右の手帳 → `cat` → `cd` のうしろの入力候補・地図の段差 → ひとりで動きはじめるときに「!」・目的・ヒント・手帳のボタン） |
| 知っているコマンドの一覧 | `help` | ターミナルに一覧を出す |
| 設定 | 「⚙ 設定」ボタン（遊び方の右） | 文字の速さ（おそい／ふつう／はやい／いっしゅん）、文字の音のオン・オフ、音量。見本のせりふで確かめられる |

**会話を「別ウィンドウ」ではなくターミナルの流れに出す理由**: 前の会話を上にスクロールして読み返せる。コマンドの結果と会話が同じ場所に出るので「cat すると人が話す」のつながりが分かりやすい。

### ターミナルの枠

今いる場所に合わせて、ターミナルのまわりの枠（ドット絵のタイル）と、枠の左上の名札が変わる。

| 場所 | 枠 |
|---|---|
| 家の中（きみの家・チョウン爺の家・パン屋） | 木目の壁 |
| 村（モリビトを止める前） | 青空と白い雲 |
| 村（モリビトを止めたあと） | どす黒い空と赤黒い雲 |
| 迷いの森（第1章） | 森の葉 |

- 家ごとには分けない。中の場所は外の場所の枠を受け継ぐ（井戸端・村はずれ・抜け穴は村の枠）
- 場所が変わると、枠が一瞬光って切り替わる
- 今後の章でも、新しい場所には必ずその場所らしい枠を用意する

## 2. 地図

- アイコンは場所の種類ごと（村・家・パン屋・井戸・道・鍵・柵・穴・森・世界…）。人は立ち絵を小さくして使う
- 中身が出ている場所は、**その場所の行と中身をまとめて枠で囲む**（細い線だけ。背景の色は変えない）。段ごとに枠の色を変える（青 → 緑 → 黄 → 桃 → 紫 → 青…）。世界（いちばん外）は囲まない。中身が出ていない場所（パン屋など）は囲まない
- 長い名前（基本情報技術者試験の参考書など）は、入りきらない分を「…」にする
- 人やものは **いまいる場所の中身だけ** 出す（地図が長くなりすぎないように）
- 地図と入力候補に出るのは、`ls`・`ls 場所`・`find` で見たものと、通った・いた場所だけ（ふるさとの村も同じ）。`cd` で入っただけでは、中の場所は載らない（本物の Linux に地図はなく、見渡すのは `ls`。新しい場所では、まず `ls` する習慣をつける）。隠れたもの（`.` で始まる）は `ls -a` で見つけたときだけ載る
- 兄の手本では、`cd ../パン屋/` の前に `ls ..` で村をのぞいてみせる（のぞいた場所が地図と候補に出る。`ls 場所` はここで手帳に載り、ピコがもっと遠くをのぞく書き方を教える）
- 中に「!」の人・ものがあるのに、まだ見渡していない場所には、今いる場所やその上でも「!」を付ける（そこで `ls` すれば見える合図）
- 村の外（`/` と `/home`）は、村長に旅を頼まれるまで「？？？」
- クリックすると入力欄にコマンドが入る（実行はしない）。できるだけ短い書き方を入れる: 中の場所なら `cd パン屋`、ひとつ上なら `cd ..`、村の中なら `cd ~/井戸端`（`~` を教わる前は `cd ../井戸端`）、村の外なら `cd /usr`
- 場所の右の住所（チルダ村の `~`、迷いの森の `/usr` など）は、打てばそこへ行けるので、青い枠で目立たせる
- 目印: ◀ いまここ ／ 🔒 入れなかった場所 ／ ⚠ ようすがおかしい人 ／ 取り消し線 止まったプロセス

## 3. 流れ

用事（おつかい）が次の場所へ行く理由になるように、家から話を始める。

| # | 場面 | プレイヤーの操作 | 🎯 目的 | 覚えること |
|---|---|---|---|---|
| 1 | タイトル → 男の子／女の子を選ぶ（ドット絵）→ 名前入力 → 「第0章 チルダ村」 → ナレーション（この世界では…）→ 兄が起こしに来る | 名前を打つ | | |
| 2 | 自分の部屋で目を覚ます。**章のはじめのイベント `opening`**: 兄が「`ls`……っと」「`cat {name}`！ おーい、起きろー！」と、呪文を当たり前のように口にしながら起こしに来る。パンのおつかいに行くことになり、主人公「どうやって行くのか、よくわからないよ」→ 兄「しょうがないな。おれがやってみせる」。**兄の手本**（入力欄にゆっくり打ってみせる）: `ls`（結果の一覧と、本棚/ の / を照らす）→ `cat 窓`（`cat 名前` を照らす）→ `cd ` で止まって入力候補を説明 → `cd 本棚` → `ls` → `cd ..`（候補の `..` を照らす）→ そのままパン屋へ: `cd ..` → `ls`（パン屋は家の中にない＝名前だけで行けるのは中にあるものだけ）→ `ls ..`（入らずに村をのぞく。見つけた場所が地図と候補に出る）→ `cd ../パ` で止まって `/` は「の中の」・Tab 補完を説明 → `cd ../パン屋/` → `ls`（地図の「!」と右の手帳を照らす）→「ここからは、おまえがやってみな」。兄が打った行は「バッシュ@moribito」のプロンプトで出る。途中で閉じたら、次に開いたときにもう一度はじめから | 見ているだけ（Space で会話を進める） | 兄のバッシュの手本を見よう | `ls`、`cat`、`cd`、`cd ..`、`/`、入力候補、Tab |
| 3 | パン屋でパンを受け取る。（プレイヤーがはじめて自分で打つのは `cat ナノ`）ナノ「妹のピコを見かけたら…」「迷ったら `pwd`」。兄は「さっきの `../パン屋` を思い出せ。つなげて書けば `cd ../きみの家/リビング`」と言って先に帰る。`pwd` を打つと、住所を読み下して「`/` は『の中の』」と案内 | `cat ナノ` → `pwd` | ナノに話しかけて、パンを買おう | `pwd`（住所） |
| 4 | ひとりで家に帰る。兄「これで移動はバッチリだな」「本当のLinuxには、候補がこんなふうに出てくる機能はないんだけどな。覚えやすいだろ？」「本当のLinux？ なにそれ？」「ああ、こっちの話」。主人公「そういえば、ナノがピコを探してたよ」→ お母さん「ピコちゃんを探しに行くなら、ついでにチョウン爺さんにもおすそわけして」。兄が `~` を教える（地図のチルダ村の右の `~` と、打った行の住所の `~` を照らす）。「`cd ~` で一気に村へ」「`~/チョウン爺の家` で一度に」 | `cd ../きみの家/リビング` → `cat お母さん` | パンを家に持って帰ろう | `cd ~`、`~/` から書くパス |
| 5 | チョウン爺にパンを渡す。「立入禁止には近づくな」「ピコは井戸端へ行った。`cd ~/井戸端` じゃ」 | `cd ~/チョウン爺の家` | チョウン爺にパンをおすそわけしよう | |
| 6 | 井戸端（ヴィム婆・イーマ爺・ピコ）。ピコ「行く前に、ここからのぞくの。`ls ~/村はずれ/柵の裏`」 | `cat ピコ` | 井戸端でピコを探そう | `ls 場所`、`ls -a` |
| 7 | 村はずれ。立入禁止に入れない | `cd 立入禁止` | 柵の裏で隠れたものを探そう | Permission denied |
| 8 | 柵の裏で抜け穴を見つける。主人公「……ほんとうに、あった……！」 | `ls -a` → `cd .抜け穴` | 〃 | |
| 9 | 石碑とモリビト。石碑「守り人の名を呼び、`kill` と唱えよ。さすれば――」（先は削れて読めない）。**`kill` は何が起こるか分からない謎の言葉**として手帳に載る（紫。説明は「？？？」。唱えたあとで「動いているものを止める（禁じられた言葉）」に変わる） | `cat 古い石碑` →（2回目からは、`ls -a` するまで「そういえば、ピコが言ってた。名前が『.』で始まるものは隠れていて、`ls -a` で見える」と思い出す）→ `ls -a` →（石碑を読むと「`kill .モリビト`」が頭に浮かぶ）→ `cat .モリビト`。`kill` は、`ls -a` で見つけるまで唱えられない（「そのようなプロセスはありません」） | 抜け穴の奥を調べよう → 石碑に書かれた「守り人」は、どこにいるんだろう…… | `kill`（謎の言葉） |
| 10 | 禁忌。主人公「どうしよう……お母さん……！」。村の枠がどす黒い空に変わる | `kill モリビト` | 石碑の言葉が、頭から離れない…… | |
| 11 | 家に帰ると、お母さんも兄も止まっている。主人公「チョウン爺なら…」 | `cd ~/きみの家/リビング` → `cat お母さん` | 家に帰って、お母さんの様子を見よう | |
| 11b | （お母さんより先にチョウン爺の家へ行っても、爺は動かないまま。話は進まない） | | チョウン爺の家へ急ごう | |
| 12 | 村長の頼み。「~ と呼んできたこのチルダ村も、世界から数えれば `/home/チルダ村`」。世界が開け、地図を照らして説明: 村では `~` で戻れた → ほかのステージは、右に書いてある `/usr` などを打てば、そのステージのいちばん大きな場所へ行ける → `/` から書けば世界のどこからでも | `cat チョウン爺` | 村の外、迷いの森へ向かおう | `/` から始まるパス（`cd /usr`） |
| 13 | 旅立ち | `cd /usr` | | 「第0章 完」 |

- 移動の教え方は3段: はじめは `..` と名前（兄の手本）→ 少し歩いたら `~`（兄、家で）→ 旅立ちの前に `/usr`（村長）。`~` を教わるまでは、地図のクリックで入るコマンドも、名前で届かないときの案内も、`..` と名前の道のり（`cd ../井戸端`、「ひとつ外の中の、井戸端」）で出す
- 名前だけで書いたものが、いまいる場所の中になかったとき（`cd`・`ls`・`cat`）、それが地図に載っている（見つけたことのある）ものなら、エラーのあとに道のりを教える。`~` を教わる前は「ここからなら `cd ../リビング`（ひとつ外の中の、リビング）」、教わったあとは「リビング の住所は `~/きみの家/リビング`（世界から書くと `/home/チルダ村/きみの家/リビング`）」。まだ見つけていないものは教えない
- 「広場」という言い方はしない（地図にない場所なので）。村そのもの（`~`）は「チルダ村」と呼ぶ
- `cat 自分の名前` は主人公自身（シナリオの `self`）。兄に起こされたあとは独り言になる
- 寄り道（窓、キャット、イーマ爺、ヴィム婆、古い日記、本棚、ベッド、井戸、掲示板）は必須ではない。2回目に話しかけると別のせりふになる
- 順番を飛ばしても詰まない。たとえば先にピコと話せば、パンのおつかいの途中でも抜け穴へ行ける
- 分かる人向けのネタ: ヴィム婆「出口の呪文はコロンとキュー（`:q`）」、イーマ爺「指を三本同時に使って扉を開ける（Ctrl+X など）」
- 主人公の一人称は、選んだ性別で「ぼく」（男の子）／「わたし」（女の子）になる（シナリオでは `{me}`）
- 隠し伏線: `ls -l` を知っている人だけ、`.モリビト` の持ち主が「スドウ」だと気づける。本棚の『チルダ村のむかしばなし』に「守り人」の話

### 赤い「!」（物語を進めるために行く場所）

- シナリオの `mark` に「この条件の間は、ここへ行く必要がある」と書く
- 地図では、その人・ものと、**そこへ続く場所すべて** のアイコンの左に赤い「!」が付く（今いる場所とその上には付けない）。たどっていけば着ける
- 隠れた場所（`.抜け穴`）が目的地のときは、見つける前から手前の「柵の裏」に「!」が付く
- 世界から色が抜けたあとも「!」だけは赤く見える

## 4. 演出

| 場面 | 演出 | 名前（YAML の effect） |
|---|---|---|
| ゲーム開始 | タイトル画面で「～ save -a ~ ～」が1文字ずつ打たれる | ― |

| Permission denied | ターミナルが左右に揺れる。地図に 🔒 | `shake` |

## 5. 📝 決めること・今後

- 立ち絵とアイコンは仮のドット絵（`src/ui/sprites.ts`）。本番の絵をどうするか（自作・依頼・素材）
- 効果音・BGM を入れるか（入れるなら kill の瞬間に音が途切れる演出が効く）
- 会話の速さの既定値（今は「ふつう」＝1文字 45ミリ秒。設定で変えられる）
- 第0章でキャットに役割を持たせるか（今は村はずれのほうを見つめるだけのヒント役）
