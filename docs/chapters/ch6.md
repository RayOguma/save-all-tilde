## 1. 概要

| 項目 | 内容 |
|---|---|
| 場所 | 坑道アナグラ（`/proc`）。本物のLinuxでも、動いているもの（プロセス）の番号の名前をした場所が並ぶ |
| 長さ | 15〜20分くらい |
| 覚えること | `ps`（目に見えない、動いているものの一覧。番号＝PID つき）、`fg 番号`（裏で動くものを表に呼ぶ）、`bg 番号`（裏に戻す）、`kill 番号`（番号で止める）、`chgrp`（場所の組を変える） |
| おさらい | `write`（裏のノーハップに声を届ける。第3章）、`mkdir`（隠れ場を作る。第4章）、`chmod`（組の者だけ入れる・のぞける。第3章）、`find`（出口の古い竪坑を探す。第1章）。`cd` はノーハップの案内で |
| 新しい人物 | ノーハップ（ハルの兄。鍛冶屋）、ミナシゴ（坑道の子ども）、影の獣 |
| 枠 | 暗い坑道。ランプの明かりと、岩の壁（📝 新しく作る） |
| テーマ | `kill` を「正しく」使う。第0章の過ちと同じ言葉を、今度は必要な選択として唱える。番号（PID）を確かめる大切さ |
| 山場 | 影の獣から隠れる場面だけ、時間制限がある（3分。残り時間は見せず、足音や画面の揺れで迫ってくることを伝える） |

## 2. 用語のたとえ

| 用語 | この世界での例え | 誰が |
|---|---|---|
| プロセス | 目には見えないが、坑道で動いている者たち | コダマ・点呼板 |
| `ps` | 点呼。名と番号札を呼び上げる | 点呼板 |
| PID | 番号札。同じ名でも、番号はひとりにひとつ | 点呼板・ノーハップ |
| `fg` | 裏で動いている者を、表（目の前）に呼び出す | ノーハップ |
| `bg` | 表の者を、裏に戻す。裏で動くこと自体は、悪いことではない | ノーハップ |
| `kill 番号` | 番号で、動いているものを止める | ノーハップ |
| `chgrp` | 場所の組（家族）を変える。組の者だけが「家族」の鍵で入れる | ノーハップ |
| 孤児プロセス | 親を失った子。本物では、守り人（PID 1）が引き取る | ミナシゴ |

## 3. 地図（案）

```
/proc（坑道アナグラ）
├── 点呼板                 「坑道で働く者は、目に見えずとも、点呼すれば名と番号札が分かる」
├── 0231番通路/            ノーハップが、裏で働いている（姿は見えない）
├── 0455番通路/            ミナシゴが眠っている
├── 0999番通路/            影の獣のすみか
└── 深い坑道/
    └── 分かれ道/          ノーハップの案内はここまで。獣が現れる。隠れ場を作る（書きこめる）
        └── 下り坂/…/古い竪坑/   出口（find で探す）。次の章（物見の塔）へ
```

- 通路の名前は、本物の `/proc` の番号に「番通路」をつけたもの。`ps` の番号と、通路の名前がつながる
- 裏で動いている者（`bg`）は、`ls` しても見えない。`fg` で呼ぶと、いまいる場所に現れる
- `fg` で呼んだノーハップは、出口まで一緒に来る（案内役）

## 5. 作るもの（システム）

- 動いているもの（プロセス）の一覧を出す `ps`（番号・状態・名前）。状態は「裏で動く」「眠っている」「暴走」など
- `fg 番号`・`bg 番号`: 裏で動く者（見えない）と、表の者（いまいる場所に現れる）を行き来させる。`fg` で呼んだノーハップは、案内役として一緒に動く
- `kill 番号`: 番号で止める。第0章の `kill 名前` との関係（📝 名前で書いたら「番号で書け」と教える）。しまっておいた `kill` を、この章で手帳に戻す（`hideIf` の条件を変える）
- `chgrp 組 場所`: 場所の組を変える。変えられるのは、自分の物だけ（`chmod` と同じ）
- 時間制限のある場面（3分）。残り時間は見せず、足音・画面の揺れが強くなっていく。時間内に、隠れ場（組がムラガレ、家族に `rwx`、よその者に何もない）ができれば成功
- ゲームオーバー（獣にやられる／まちがえて `kill` する）: 場面を見せたあと、直前からやり直す（その場面の前の状態を、セーブとは別に取っておく）
- 第3章の鍛冶場・名簿の「鍛冶の兄」を、名前（ノーハップ）にそろえる（📝 作るときに）
- 坑道の枠、ノーハップ・ミナシゴ・影の獣の立ち絵、通路・点呼板・竪坑のアイコン

## 6. 決まったこと

- ハルの兄の名前は、ノーハップ（`nohup`＝見ている人がいなくなっても、動き続けるようにする。支えが弱っても、暗い坑道で働き続けた兄）
- 通路の名前は「0231番通路」のように、番号＋番通路
- 薬を渡すとき、主人公はムラガレの組に入れてもらった話をする（隠れ場の伏線）。ノーハップは、薬の礼に出口まで案内してくれる
- ミナシゴは「守り人さまが拾ってくれるはずだった」と言う（本物の孤児プロセスは PID 1 が引き取る。主人公の `kill` がここにも届いていた）。主人公は言い出せないが、「賢者に会えば、親のこともなんとかなるかもしれない」と励まし、`bg` で裏に隠れていてもらう
- 獣から隠れる場面は、ノーハップが `mkdir`・`chgrp`・`chmod` の書き方をおさらいしてくれる（時間制限があるので、ヒントを控えめにする決まりの例外）
- 隠れる場面だけ、時間制限（3分）。残り時間は見せない。間に合わなければゲームオーバー（獣が現れる直前からやり直す）
- 隠れたあと、獣は去るが「このままじゃ進めない」→「`kill` するしかないか」→「`kill`！？」から、正しい `kill` の場面へ
- まちがえてノーハップ・ミナシゴを `kill` したら、ゲームオーバー（コダマが離れ、主人公は自責の念で動けなくなる）。`kill` を唱える前からやり直す
- 出口は扉なし。ノーハップが教える名前（古い竪坑）を、`find` で探して抜ける
- スドウは、古い竪坑のほうへ抜けていった（どこまで行ったかは分からない）
- 見取り図の写し（`cp`）は入れない
